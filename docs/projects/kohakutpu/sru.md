# Streaming Row Unit

`src/kohakutpu/sru/`, top `sru_cu` (mesh endpoint) around `sru_core`.

The SRU takes the streams a matmul cluster emits (or memory holds), runs a
pass program on every element, reduces rows, and sends the result to the next
consumer: MXFP7 entries into a cluster's L1, f16 into memory or a peer. A
kernel is a configuration: a few pass programs and a finalise program, no
instruction stream. One RTL builds every profile in §8.

## 1. What it consumes and produces

| Side | Format | Shape |
|---|---|---|
| in: stream A | FP16 4 x 4 sub-tiles, lane `4r + c` | a CU_DATA COUNT stream (a cluster's drain), or memory runs |
| in: stream B | as A | memory runs, paired word for word with A |
| out: memory or a peer | f16 sub-tiles, or MXFP7 A / B entries | write bursts of up to 8 words, or CU_DATA bursts on credits |
| row state | three E8M15 scalars a row, 512 rows | loaded and stored by instruction |

A JOB is `NSR` sub-rows of `NW` words: sub-row `g` is rows `4g..4g+3`,
word `h` its columns `4h..4h+3`, the order a cluster drains a tile in.

## 2. Folder

| Path | Holds |
|---|---|
| `lane/` | `sru_plane` (the pool lane: FMA or table function per issue, one DSP), `sru_dsp` (DSP48E2 wrapper), `sru_exp2_rom.vh` (generated) |
| `pool/` | `sru_pool` (the lanes, op store, slot clock, history, operand network, function tables) |

| `sru_cfg.vh` | the configuration map, generated by `scripts/py/sru/cfg.py` |

## 3. Flow

| # | Block | Does | Rate | Parameter |
|---|---|---|---|---|
| 1 | sub-row buffer | holds FP16 sub-rows (two halves) so a sub-row replays after its statistics | a word a cycle | `BUF_WORDS` |
| 2 | R1 | per-row max of the words as they arrive (FP16 order) | a word a cycle | `HAS_R1` |
| 3 | unpack | FP16 -> E8M15, exact; B likewise | a word a cycle | `HAS_B` |
| 4 | mask | `col - row > DHI` or `col >= CLIM` takes `MVAL` | a word a cycle | `HAS_MASK` |
| 5 | pool | the pass program on every element | a word per II cycles | `F_LANES`, `HAS_FN`, `TAB` |
| 6 | R2 | per-row sum of the program's result | a word a cycle | `HAS_R2` |
| 7 | out | E8M15 -> FP16; MXFP7 pack; credited out FIFO | a word a cycle | `HAS_MX7`, `MX_DSP` |
| 8 | finalise | a pass's scalar program over the sub-row's 4 rows: ADD/SUB/MUL/FMA on pool lane 0, MOV/MAX/MIN on a compare-select | -- | -- |

A pass of no ops sends the word straight through, a word a cycle. Only one
pass is in the pool at a time: the issuer drains it at a pass change.

## 4. The pool

`F_LANES` lanes (16, 8 or 4). Lane `l` works on element `l + F_LANES * e` of
chunk `e`; a word is `M = 16 / F_LANES` chunks.

**The lane** (`sru_plane`) issues one op a cycle, either kind, with one
latency (16 cycles), on one DSP48E2:

| op | computes | DSP A x B + C |
|---|---|---|
| 0 FMA | `(+-a) b + (+-c)`, E8M15, one rounding | `sig_a x sig_b + aligned sig_c` |
| 1 function | `(-1)^sg (c0 + c1 t) 2^(es + n)` from a table segment, `x = a`, `k = b` | `(t << cs) x c1 + (c0 << 13)` |

Both kinds share the addend shifter, normalise and round. The function front
end maps `v = x * 2^pre` to Q9.24, then EXP: `w = v - (floor(k) << 24)`,
`n = w >> 24`, segment from the fraction (1,024 segments; 128 in the ROM
kind); or FIX: `v` in `[-16, 16)` picks one of 1,024 segments of 1/32 and
`n = 0`. A 36-bit entry is `{sg, es[5:0], c0 fraction[15:0], c1[12:0]}`, `es
= -32` a zero segment, `c1` in units of `2^(cs - 15)`. `TAB` is `ram` (a
loadable 1,024 x 36 table, one RAMB36 per lane pair) or `rom` (exp2 only, LUT);
`HAS_FN = 0` builds FMA lanes only.

`HAS_MANT` adds two table modes on the RAM table, both from `x = m 2^e`:
MANT takes the segment from `m` (`n = +-e`, the result's sign is `x`'s times
the entry's: `1/x` with NEG), HALF from `(e mod 2, m)` (`n = +-floor(e/2)`, a
negative `x` is NaN: `1/sqrt(x)` with NEG, `sqrt(x)` without). A zero is
infinite with NEG and zero without; an infinity the opposite; both keep
`x`'s sign. `FIN_RCP` builds a mantissa ROM on pool lane 0 (`1/m` and
`1/sqrt(m 2^r)`, 128 segments each, LUT) that the finalise's RCP and RSQRT
read, on any lane kind (`HAS_FN = 0` too).

Worst relative error where `|f| >= 2^-8` (`scripts/py/sru/fn_vectors.py`):
exp2 2^-14.9 (RAM), 2^-15.2 (ROM), sigmoid 2^-13.6, Phi (at `pre = 1`)
2^-12.9; 1/x 2^-14.9 (table and ROM), rsqrt 2^-14.8, sqrt 2^-14.9.

**The schedule.** A pass program is `NOPS` ops; `II = NOPS * M` cycles a word.
Slot `s = i*M + e` of every II-cycle window issues op `i` on chunk `e` on all
lanes. Op `i` works on the word taken `KW_i` windows earlier; a result is
readable `LDEP = 18` slot cycles after its op's slot. `scripts/py/sru/cfg.py`
(`schedule`) places the ops and computes every depth; a program it cannot
place is refused, never run.

**Operands**, per op:

| | sources |
|---|---|
| a | X (the word's element), B, O (the pair partner's X, element `j ^ 1`), H |
| b | K (constant), R (one of the row's three scalars), C (one of the column's two constants), B, X, H |
| c | as b |

H is an earlier op's result through one of `H_TAPS` (1 or 2) result taps.
There is no register file: per lane, X and B sit in shift registers a window
deep each, results in `H_TAPS` shift registers a cycle deep each (32 deep).

**Throughput** at 16 lanes: a 1-op program runs a word a cycle, a 2-op
program a word per 2 cycles; 8 lanes double that, 4 lanes quadruple it.

## 5. Passes, row state and the finalise

| `BUF` | passes |
|---|---|
| 0 | pass 0 only, from A (and B) |
| 1 | pass 0 fills the buffer (R1 taps it); passes 1..`NPASS` replay it |

Row state: three scalars a row in a 512 x 72 RAM, loaded into a working set
per sub-row (two, by sub-row parity) and stored back after it. After a pass's
statistics land (R1's max for the fill pass, R2's sum otherwise) and the pool
is empty, its finalise program runs: up to 16 ops (MOV, ADD, SUB, MUL, FMA,
MAX, MIN, RCP, RSQRT), each over the sub-row's 4 rows, sources R0..R2, T,
ST1, ST2, K0..K3. ADD/SUB/MUL/FMA and RCP/RSQRT (`FIN_RCP`, the mantissa ROM)
run on pool lane 0 (MUL adds a zero of the product's sign, so a zero product
keeps its sign); MOV/MAX/MIN on a compare-select with the reducers'
sign-magnitude key, a zero leaving as +0. A profile with no pool finalises
MOV/MAX/MIN only; without `FIN_RCP`, RCP and RSQRT move A.

## 5a. FP16

`F16_IEEE` picks the FP16 form of every FP16 the unit reads (A, B, column
constants) and writes: 1 IEEE (subnormals, inf, NaN); 0 the clusters'
accumulator form, the one `mx_fpacc_to_fp16` emits: exponent 0 is a signed
zero and 1..31 ordinary binades in; out rounded to nearest even at the
value's binade, a signed zero below 2^-14, +-65504 at 2^16 or above (inf
and NaN included).

## 6. Configuration

32-bit words at 8-bit addresses, written by the `CFG` instruction; the map
is one Python table (`scripts/py/sru/cfg.py`), `sru_cfg.vh` is generated from
it. Global words hold the job (`NW`, `NSR`, `NPASS`, `BUF`, `USE_B`, `OUT`,
`MASK`, `R1`, `ROW0`, `COL0`, mask fields, `K0..K3`); a pass has `NOPS`,
`OPBASE`, `R2EN`, `EMIT`, `FINLEN`, `FINBASE`; the op store holds 16 ops of 4
words (kind, sources, negations, row/column selects, function fields, two
constants, schedule fields); 16 words hold the finalise program.

## 7. The mesh endpoint

| Op | Instruction |
|---|---|
| 1 `CFG` | one configuration word |
| 2 `LOAD` | function table, column constants or row state from memory |
| 3 `RUN` | one job; A from memory or a CU_DATA COUNT stream, out to memory or a peer; retires when done and acked |
| 4 `STORE` | row state to memory (f32, a row a word) |
| 5 `POST` | a CREDIT to a unit |

Memory reads go out only for FIFO space already reserved; a CU_DATA
producer is posted A's FIFO depth at `RUN` and 8 more for every 8 words
taken; a peer burst waits for its credits; a burst header leaves only with
its whole burst in the out FIFO. The field layouts are in `sru_cu.v`'s
header.

**Reset.** The raw active-low `resetn` meets one `kh_rst_sync` in `sru_cu`
(asynchronous assert, synchronous release). Only control state resets,
synchronously from that local release; data registers load without reset.

## 8. Profiles

`scripts/py/sru/profiles.py` is the table; benches and OOC read it.

| Profile | Pool | Other | Role |
|---|---|---|---|
| `strong` | 16 lanes, function front ends, RAM table with MANT / HALF, 2 result taps | R1, R2, mask, B, buffer, MXFP7, RCP / RSQRT | the full catalog |
| `rom` | 16 lanes, exp2 ROM, 2 taps | as `strong` | softmax / flash without table BRAM |
| `mid` | 8 lanes, RAM table with MANT / HALF, 1 tap | as `strong` | every program at half rate |
| `spu` | 16 FMA lanes, 2 taps | as `strong` | affine, statistics, norms |
| `pack` | none | MXFP7 | format unit |

Every profile reads and writes the accumulator FP16 form (`F16_IEEE = 0`).
