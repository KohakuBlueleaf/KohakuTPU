# TG: the tinygrad device (`ktpugrad`)

`kohakutpu.application.ktpugrad` makes `KTPU` a tinygrad device: every
kernel tinygrad schedules is planned (`lower.plan`), run as generated DSL
kernels (`run.execute`); constant plans evaluate on the host (TG.PLAN.004). Buffers and
forms are the runtime's (`tensor.md` API.FORM, API.MEM). Clause format, ids
and evidence tags: `../README.md`.

Evidence on this page:

- `silicon`: LeNet (`software/kohakutpu/application/examples/tinygrad/mnist_mlp.py
  --model lenet --no-jit`, v9t6 sysnode 0 over XDMA, 2 steps of 64 and a
  64-image evaluation) trained on the card on 2026-10-21 matching the CPU
  (loss 2.3320 / 2.2305 vs CPU f32 2.3324 / 2.2289; accuracy 0.5312 vs
  0.5469),
  with the code at `af7c1bb`. A clause is `silicon` only where the code it
  states is the same as at `af7c1bb` (its evidence names the code compared)
  and the run necessarily took it. A refusal or error path is never `silicon`.
  The kernels it ran, by kind (rows 170, walk
  74, transpose 38, copy 36, expand 35, flat 32, fill 30, quant 25, mm 15).
- `RTL`: a tinygrad run on the Verilated card (the runtime's default model).
- `unproven`: neither. Offline checks are not hardware-value evidence. TinyJit replay
  has never run on the card.

Machine facts are machine-schema parameters with the v9t6 value in brackets:
`vc.descriptors` [8 memory views a vector-core kernel], `die.word_bytes`
[32], `vc.lanes` [16], `vc.count` [2], `mg.count` [2], `card.profiles` [sys
clock: low 100 MHz, ship 300 MHz] (`boards/multimesh_v9t6.json:25-45`,
`:74-95`). The stack's own constants: a column block of 32 values (the
stack's block width), a widest block of 256 columns, and a statistic word of
`vc.lanes` values.

Generated kernels receive core and cluster counts from the active machine,
without defaults. Stage trips cover all `node.vc` instances that have work,
with the exact-once split of API.ROW.007, balanced by default (RUL.016).
Both tensor frontends use `_product` for products: N is padded to whole
`vc.vlmax / mg.lanes` column blocks from the schema (one vector register
across a cluster GT4 row band), while logical N is retained.

Registration creates tinygrad.runtime.ops_ktpu in sys.modules if absent or reuses it, assigning KTPUDevice without writing into tinygrad. It snapshots installation state, registers the device, saves the initial state once, applies pins and buffer cap, installs matchers and runtime hooks, and refreshes optional hooks. A BaseException restores the snapshot and propagates; successful installation clears fusion decisions. - **TG.REG.004** `unproven` `python -m kohakutpu.application.ktpugrad --autoload [--site DIR]` writes `kohakutpu_ktpu.pth` holding `import kohakutpu.application.tinygrad_hook` into site-packages (default: this interpreter's purelib); `--remove` deletes it; `--check` runs a [64, 128] softmax on KTPU against numpy and prints the error, kernel count and cycles. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/__main__.py:19-59; software/kohakutpu/application/kohakutpu/application/tinygrad_hook.py:13-39; doc: docs/projects/kohakutpu/tinygrad.md:30-32)

For KTPU it caches plans by `ast.key` and retains the exact AST in `PLAN_ASTS`; the same key presented by another AST object raises `KTPUUnsupported`. Otherwise it plans a missing key and returns a PROGRAM containing the sink with `Estimates(ops=out_n, lds=2*out_n, mem=2*out_n)`, a LINEAR of PARAMs, source text and the AST key as binary. - **TG.SEAM.002** `unproven` If KTPU lowering raises Refused, to_program raises KTPUUnsupported, naming the kernel and reason and appending TG.PLAN.010; its clause attribute is TG.PLAN.010. This exception path does not invoke another execution backend. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/seam.py:309-316; software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/plans.py:10-16; evidence: No named RTL witness of this exception path established.)
- **TG.SEAM.003** `unproven` `capture(run, strict=True)` returns every ast `run()` hands to lowering, in order; it requires the seam installed (else `KTPUUnsupported`); with `strict=False` a refusal ends the run and the asts so far are returned. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/seam.py:450-466)

## 2. tinygrad options pinned

- **TG.PIN.001** `silicon` While installed: `NOOPT=1`, `BEAM=0`, `PARALLEL=0`, `NO_MEMORY_PLANNER=1`, `DEFAULT_FLOAT=half`, `SPLIT_REDUCEOP=0`, `WINO=0`, `PCONTIG=0`, process-wide. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/seam.py:77-86, :409-412; evidence: Default-mode LeNet installation/scheduling path matches af7c1bb:software/application/kohakutpu/application/ktpugrad/seam.py:54-63, :216-219.)
- **TG.PIN.002** `silicon` Installation sets tinygrad's KTPU buffer cap to the software constant `MAX_BUFS=8`, corresponding to `vc.descriptors` [8]: one output and seven reads. The seam does not read the active machine's descriptor count for this cap. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/seam.py:87-88, :413; evidence: af7c1bb:software/application/kohakutpu/application/ktpugrad/seam.py:64-65, :220 sets the same constant in the LeNet installation path.)
- **TG.PIN.003** `silicon` Producer inlining follows `KTPU_TINYGRAD_FUSE`: `elementwise` (default) keeps a computed producer read inside a consumer's reduction as its own kernel, inlining reloads (a buffer read, or one padded by an index-only gate with zero else) and elementwise consumers as tinygrad does. The rule applies only to buffers on KTPU. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/seam.py:100-137, :140-145, :402-405, :414-416; evidence: Default-mode LeNet installation/scheduling path matches af7c1bb:software/application/kohakutpu/application/ktpugrad/seam.py:75-115, :222-225.)
- **TG.PIN.004** `unproven` For KTPU computed producers, KTPU_TINYGRAD_FUSE=0 prevents producer removal; 1 selects the original matcher. bounded retains the elementwise reduction cut and also cuts producers with reductions, more than max_alu operations, (reads+1)*tile_words > l1_words, alu*instructions_per_alu > imem_words, or twice intermediate byte count < min_saved_bytes. Software defaults are 32 ALU operations, 512 L1 words, 32 tile words, 1024 instruction words, 8 instructions per ALU and zero minimum saved bytes. KTPU_FUSE_<NAME> overrides by integer conversion; capacities must be positive and minimum saved bytes nonnegative. Invalid mode/budget raises ValueError. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/seam.py:121-137, :399-416; software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/fusion.py:24-34, :37-84)

Its rt property resolves the process attached runtime at each use; assignment attaches a runtime. synchronize drains submissions. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:535-559; evidence: af7c1bb:software/application/kohakutpu/application/ktpugrad/device.py:298-308 stores runtime at construction and has no-op synchronization.)
- **TG.DEV.002** `unproven` KTPURenderer declares supports_float4, has_local, has_shared and has_threads false, shared_max zero, global_max and local_max (1,1,1), and no tensor cores. render raises NotImplementedError; normal lowering uses the seam. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:129-146; evidence: Declarations and refusal match af7c1bb:software/application/kohakutpu/application/ktpugrad/device.py:82-99; LeNet witnesses configuration, not the render refusal.)
- **TG.DEV.003** `unproven` `KTPUProgram(dev, obj)` looks up its plan by `bytes(obj.lib)` and takes slots from `obj.signature`. Calls map buffers to sorted slots and invoke `recipe.submit` in the runtime submission scope. Execution can reuse a kept result, replay an eager recipe or call `run.execute`; eager recipes are bypassed when disabled, inside an active fused scope, during recording or under placement. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:152-168; software/kohakutpu/application/kohakutpu/application/ktpugrad/captured/recipe.py:449-493; evidence: af7c1bb:software/application/kohakutpu/application/ktpugrad/device.py:105-120 calls run.execute directly.)
- **TG.DEV.004** `unproven` A waited program call collects each submitted result through its completion and returns the sum of completed cycles divided by card.sys_hz. Without a wait, it returns no timing value if any returned result is still a submission; otherwise it returns that same completed-cycle timing. dev.last_runs holds the runs or submissions. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:54-57, :174-181; evidence: No named RTL witness of this timing contract established.)
- **TG.DEV.005** `unproven` Allocation returns Storage with requested logical bytes backed by runtime allocation. Accessible extent rounds to line_bytes and physical reservation to arena alignment. Free releases owned primary/side allocations when storage-sharing references permit; allocation pins can postpone physical reuse. _offset returns StorageView, adding offsets for an existing view. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:67-72, :123-126; software/kohakutpu/application/kohakutpu/application/runtime/memory/storage.py:48-56, :254-272; software/kohakutpu/application/kohakutpu/application/runtime/device/allocation.py:28-43, :160-169; software/kohakutpu/application/kohakutpu/application/runtime/memory/arena.py:83-90, :152-166; evidence: af7c1bb:software/application/kohakutpu/application/ktpugrad/device.py:43-48, :76-79 has the same entry points; parity of current sharing/reservations/queued lifetimes not established.)
- **TG.DEV.006** `unproven` `copyin` settles and unshares storage, waits for pending accesses to its forms and writes bytes. A whole owner write zeroes its final partial word. It marks FLAT written, retains host bytes only for a whole-buffer write from offset zero and clears the element type. A whole upload with remembered `host_f16_dtype` also requests its f16 form. ### Queued execution contracts

The knob is `KOHAKUTPU_QUEUE` (`1`: queued, default; `0`: synchronous), or the
attached runtime's `queued` option. The clauses below describe current submission code; no named existing
RTL witness for the complete queued contracts is established here.

- **TG.QUEUE.001** `unproven` Within a queued scope a run can return a submission without immediate collection. Admission, allocation pressure, submission limits and cross-sysnode fences can collect earlier work during later submission. A host read collects through the last pending writer of its allocation, preserving submission order. (code: software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:79-98, :126-179, :218-222, :360-364; software/kohakutpu/application/kohakutpu/application/runtime/device/allocation.py:122-132, :190-201; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.002** `unproven` Admission sums reserved sizes of the union of allocations referenced by current submissions and the proposed run. Exceeding queue_bytes collects oldest submissions until it fits; a run exceeding the budget alone raises OutOfMemory. Scratch windows and explicit bindings participate. (code: software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:151-169, :213, :244-262, :361-364; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.003** `unproven` Owner release does not return a physical span while retained references remain. Successful collection releases submission references; physical reuse requires owner release and no remaining references. Recordings and other submissions may retain references. (code: software/kohakutpu/application/kohakutpu/application/runtime/memory/arena.py:124-135, :152-176; software/kohakutpu/application/kohakutpu/application/runtime/device/allocation.py:134-169; software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:470-476; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.004** `unproven` Before a tinygrad host upload, the allocator settles deferred content, detaches shared content and waits through pending readers and writers of each current form allocation. Runtime address writes likewise wait through all pending uses. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:74-80; software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:79-88; software/kohakutpu/application/kohakutpu/application/runtime/device/allocation.py:171-187; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.005** `unproven` Explicit synchronization collects submissions in order. A collection error propagates and can stop the drain. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/device.py:557-559; software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:434-482, :484-486; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.006** `unproven` For each target sysnode with a queue, admission bounds outstanding entries by min(sq_n,cq_n). Deferred members of one eager group count as one entry; max_inflight can impose a separate bound. (code: software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:60-65, :151-169, :218-222; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.007** `unproven` For a non-native, non-split log on a card supporting recorded submission, replay(log,wait=False) returns submissions without final collection; admission, host-write dependencies and cross-sysnode fences may still collect during replay. Host reads collect pending writers. wait=True collects returned submissions; native replay and fallback card replay are synchronous. Split replay submits prepared regions, preserves intervening host writes and collects the prior replay epoch before reusing its event slots and scratch; wait=True also collects the new submissions. (code: software/kohakutpu/application/kohakutpu/application/runtime/device/replay.py:58-125, :213-246, :262-267; software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:79-98; software/kohakutpu/application/kohakutpu/application/runtime/device/allocation.py:190-201; software/kohakutpu/application/kohakutpu/application/runtime/graph/split_recorded.py:31-46; evidence: No existing named RTL witness established for this contract.)
- **TG.QUEUE.008** `unproven` On NodeError during collection, runtime prefixes the message with the recorded plan name or generated run name, and the generated run name. It records failure, marks later in-flight results discarded with the failing completion description, and refuses further healthy operations. (code: software/kohakutpu/application/kohakutpu/application/runtime/device/submission.py:69-77, :380-381, :443-461; evidence: No existing named RTL witness established for this contract.)

## 4. Plans (lowering)

- **TG.PLAN.001** `silicon` lower.plan accepts one stored-loop-nest envelope: SINK with one source STORE or END(STORE,ranges...). Each END range is RANGE with an integer CONST first source. Bare STORE supplies no output ranges. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:116-120; software/kohakutpu/application/kohakutpu/application/ktpugrad/uops.py:14-37; evidence: LeNet envelopes use rules matching af7c1bb:software/application/kohakutpu/application/ktpugrad/uops.py:15-38 and af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:104-108.)
- **TG.PLAN.002** `silicon` Store targets a buffer via INDEX; after unfolding and domain normalization its index is an affine dense row-major walk at zero element offset. Indexed ranges belong to the output nest, every output range of extent greater than one is indexed, and ranges are ordered by descending stride. From innermost outward required stride starts at one and multiplies each extent. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:121-133, :300-313; software/kohakutpu/application/kohakutpu/application/ktpugrad/uops.py:48-72, :85-89; evidence: LeNet store checks match af7c1bb:software/application/kohakutpu/application/ktpugrad/uops.py:54-78 and af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:109-121, :288-301.)
- **TG.PLAN.003** `silicon` Unfolding recognizes constant floor divisions/remainders of ranges or nested constant floor divisions. Interior split points must divide the extent and each successive point divide by its predecessor; admitted ranges split into mixed-radix digits, including reduction ranges. Positive-constant quotient/remainder folds affine when nondivisible coefficient terms plus constant remainder remain within [0,c); otherwise this transformation does not fold it. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:170-292; evidence: LeNet pooling/flattening/GroupNorm reshape paths; implementation matches af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:158-280.)
- **TG.PLAN.004** `unproven` Planning selects const for index_only expressions, then matmul for admitted contractions, copy for one non-reduced Load with parameter slot, matching output coefficient map, zero offset and matching dtype, otherwise vector. index_only excludes INDEX, PARAM, LOAD and REDUCE. Constant plans evaluate with numpy, broadcast to output shape and cast to output dtype; half intermediates use float64 operands and fp16.write after each operation. Unsupported evaluator operations raise ValueError. Execution writes contiguous constant bytes to the output primary allocation and marks them current without a device kernel. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:134-167, :316-317; software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/fold.py:26-50, :53-129; software/kohakutpu/application/kohakutpu/application/ktpugrad/run/__init__.py:174-185; evidence: af7c1bb:software/application/kohakutpu/application/ktpugrad/fold.py:25-45 does not promote half operands to float64 or apply fp16.write after each intermediate.)
- **TG.PLAN.005** `silicon` Access records parameter slot, scalar dtype, affine range coefficients and element offset. Absent index gives empty coefficients and zero offset. Equal reads share an access-list entry referenced through Load. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:34-49, :295-297, :397-420; software/kohakutpu/application/kohakutpu/application/ktpugrad/uops.py:48-72, :85-89; evidence: LeNet buffer reads use construction/deduplication matching af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:385-408.)
- **TG.PLAN.006** `silicon` Mappings include ADD/add, MUL/mul, RECIPROCAL/recip, EXP2/exp2, LOG2/log2 and WHERE/where with operand order preserved. RECIPROCAL(SQRT x) becomes rsqrt. Constant lowered WHERE conditions select the corresponding already-lowered arm. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:90-110, :358-364; evidence: Mappings match af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:80-98, :346-352; card vadd 4441, vmul 7225, vinv 664, vexp2 378, vlog2 8, vsel 1272, vrsqrt 131.)
- **TG.PLAN.007** `unproven` REDUCE maps ADD to sum, MAX to max and MUL to prod. Operator comes from first tuple argument or the non-tuple argument; operands after the value must be RANGE. Other operators or non-range operands raise Refused. Reader records the union of reduced ranges and each reduction expression ranges separately. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:113, :384-395; software/kohakutpu/application/kohakutpu/application/kernels/expr.py:54-57; evidence: af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:101, :372-383 has these rules; card sum/max tally does not establish prod or refusals.)
- **TG.PLAN.008** `unproven` Contraction matching requires exactly one ADD reduction with at least one reduction range over a MUL of two buffer INDEX expressions after float-cast peeling; both reads must lower to Load. K comprises reduction ranges of extent greater than one, or the first reduction range when none is live, and both operands must index every K. With KTPU_MM_FUSE_RANGES=1 and no explicit output strides, optional fusion joins output-range pairs only when every product and epilogue access satisfies c(p)=extent(q)*c(q); finding no join does not reject the contraction. Both operand orders are tried. Exactly one B-only live output range must be innermost (N); at least one A-only live range must exist, with the innermost chosen as M. Remaining output ranges become batches. The epilogue replaces the reduction by Load(0), renumbering remaining accesses from one. Range fusion defaults off. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:149-153, :455-527, :530-626)
- **TG.PLAN.009** `silicon` In a data-dependent expression, a float cast returns the lowered source without inserting conversion. Index-only expressions take constant/table folding first. (code: software/kohakutpu/application/kohakutpu/application/ktpugrad/planning/lower.py:338-351, :374-382; evidence: LeNet half reductions; float-cast path matches af7c1bb:software/application/kohakutpu/application/ktpugrad/lower.py:326-339, :362-370.)
- **TG.PLAN.010** `unproven` Unsupported data operations raise Refused with clause TG.PLAN.010; BITCAST and THREEFRY have explicit refusals. to_program wraps planning Refused as KTPUUnsupported carrying that clause and adding it to diagnostics. ## 5. Running a plan

A row reduction's statistic is compact f16 storage, 16 row values a 32-byte
word, including its final partial word. Producers, statistics-only math,
read-back and row broadcasts use this one form (RUL.030); there is no
`[n, 32]` statistic layout. A full row output materialises register rows
from those values before packing ordinary rows.

## 11. Tolerances the tests hold

- **TG.TOL.001** `unproven` The per-kernel checker calls a store exact for a parameter read, exactly representable f16 literal, or index-only selection between such values; reductions/matmul have separate classes.
