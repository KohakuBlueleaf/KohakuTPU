# L2 program

L2 is batches of work on named units: every value has a hardware-sized shape
and a named space, every op is one hardware feature or a fixed instruction
pattern of known cost, and the compiler decides only addresses, registers,
issue order, sync and packaging. `pipeline.compile_l1` runs the L2 -> L2
passes, lowers the body to L1 text ([../l1/program.md](../l1/program.md)) and
runs the image scheduler. Clause format, ids and evidence tags:
[../README.md](../README.md).

**Path prefixes.** Rust crate paths are relative to `software/rust/crates/`. `L/` =
`software/language/kohakutpu/language/`, `K/` =
`software/application/kohakutpu/application/`, `E/` =
`software/language/kohakutpu/language/examples/`. Doc pages: `l2p` =
`docs/spec/l2-program.md`, `ktpu` = `docs/projects/kohakutpu/ir/ktpu.md`.

**Evidence.** The 455 card kernels were compiled from L2 by the compiler of
2026-10-21; an L2 construct whose L1 lowering appears in them is `silicon`
(per the statement tally of those kernels). They predate the 16-a-word
statistic pack, `unpack lane=`, `xrot`, gather / scatter index views and the
lane relayout. A refusal or error path is never `silicon`. `RTL` names a
test that runs on a Verilated card: `tl1::NAME` is
`software/application/tests/test_l1_examples.py` (the L2 examples compiled
through `compile_l1`: a construct counts only when it survives the passes
into the lowering), `tt::NAME` is `software/application/tests/api/test_tensor.py`
(its recorded run, `docs/projects/kohakutpu/api.md:78-81`, is on `build/v9f`
and predates the current tree), and `software/application/tests/ktpugrad/test_tinygrad.py`
(76 of 80 passing on the current tree; the 4 misses are MXFP7 precision).
`software/rust/crates/ktpu-l2/tests/ported.rs` runs offline:
it leaves hardware-value clauses `unproven`.

## 1. A body

- **L2.BODY.001** `silicon` `fn NAME.l2(PARAM: TYPE @SPACE(LAYOUT), ...)` holds, first, `NAME = buffer : TYPE @SPACE(LAYOUT)` scratch statements, then the body. (code: ktpu-l2/src/ir/read.rs; doc: l2p:56-63; evidence: every silicon kernel's scratch `h1`, `h2`, ... parameters)
- **L2.BODY.010** `unproven` A `buffer` without a target or a type is refused "NAME = buffer : TYPE @SPACE(LAYOUT)". (code: ktpu-l2/src/ir/read.rs; evidence: refusal, offline only)
- **L2.BODY.002** `silicon` Read-time expansion (constant arithmetic) runs first, but an L2 body keeps its loops. (code: ktpu-l2/src/ir/read.rs, L/text/meta.py:65-75, 166-176; doc: l2p:73-75; evidence: 455 kernels (`loop` 160 / 137 from kept `for`s))
- **L2.BODY.018** `unproven` In an L2 body a `when` whose condition is not constant is kept for the reader to decide per instance, and a computed name with a loop index is kept; `when` on constants and `expand` fold at read time. (code: L/text/meta.py:65-75, 166-176; evidence: no record shows a card kernel's L2 holding a `when` or a computed name (the L1 keeps none); `expand` and folded `when` are RTL at L1 (`docs/spec/stack/l1/program.md` L1.EXP.003-.004))
- **L2.BODY.003** `silicon` `par VAR in LO..HI on UNIT[EXPR]` makes instances that run concurrently, instance VAR on unit UNIT[EXPR]; UNIT is `mg` or `vc`. (code: ktpu-l2/src/ir/read.rs; doc: l2p:65-68; evidence: `par ... on vc[..]` / `mg[..]` in every compiled kernel)
- **L2.BODY.004** `silicon` `for VAR in LO..HI` runs its iterations in order on the enclosing instance. (code: ktpu-l2/src/ir/read.rs; doc: l2p:69-72; evidence: 455 kernels (`loop` 160 / 137, the mm kernels' K loops))
- **L2.BODY.011** `RTL` UNIT may be `node`. (code: ktpu-l2/src/ir/read.rs; evidence: E/l2/multinode/silu2.ktpu:6 `par n in 0..2 on node[n]`: tl1::test_l2_silu_on_two_nodes)
- **L2.BODY.012** `unproven` `UNIT[any]` leaves the unit to the place pass; another UNIT is refused "a par runs on node[i], mg[i], vc[i]"; `node[any]` is refused "nodes are named: node[EXPR]". (code: ktpu-l2/src/ir/read.rs; evidence: no record shows a card or tl1 kernel reaching the place pass with `[any]`; refusals)
- **L2.BODY.013** `RTL` `for VAR in LO..HI pipe=K` takes K an integer >= 1. (code: ktpu-l2/src/ir/read.rs; evidence: E/l2/fused/tilesilu.ktpu:9 `pipe=2`: tl1::test_l2_tiles_drain_into_the_cores_and_overlap)
- **L2.BODY.014** `unproven` `pipe=K` with K < 1 is refused ("pipe=K: K iterations in flight, K >= 1"); any other `for` argument is refused "for VAR in LO..HI [pipe=K]". (code: ktpu-l2/src/ir/read.rs; evidence: refusals, offline only)
- **L2.BODY.005** `unproven` A `par` or `for` without `VAR in LO..HI` ("wanted `par VAR in LO..HI ...`"), over a non-span ("`par` ranges over LO..HI"), or with an empty body ("`par` has no body") is refused; a statement other than `par`, `for`, `when`, `if` with a block is refused "`OP` takes no block". (code: ktpu-l2/src/ir/read.rs; evidence: offline Rust L2 witnesses (`ktpu-l2/tests/ported.rs`))
- **L2.BODY.006** `RTL` `if sticky` (a block) is a run-time condition of a vector core, inside its stream loop. (code: ktpu-l2/src/ir/read.rs; doc: l2p:75-76; evidence: E/l2/vector/lazysoftmax.ktpu:15: tl1::test_l2_sticky_softmax_on_both_paths)
- **L2.BODY.007** `RTL` A `par` over nodes may hold unit `par`s. (code: ktpu-l2/src/ir/read.rs; evidence: E/l2/multinode/silu2.ktpu: tl1::test_l2_silu_on_two_nodes)
- **L2.BODY.008** `silicon` A value is `NAME = OP ARGS : TYPE`; an effect (a store, a drain, a send) is `OP ARGS`. A type is `DTYPE[constant dims] @SPACE[(MODE)]`. (code: ktpu-l2/src/ir/read.rs; doc: l2p:61-62; evidence: 455 kernels)
- **L2.BODY.015** `unproven` Any run-time condition but `if sticky` is refused "if sticky (a block): the only run-time condition"; `if sticky` outside a vector core's stream loop is refused "if sticky is a vector core's (its stream loop)". (code: ktpu-l2/src/ir/read.rs; evidence: refusals, offline only)
- **L2.BODY.016** `unproven` A `par` inside a unit's instance is refused "a par inside a unit's instance". (code: ktpu-l2/src/ir/read.rs; evidence: refusal, offline only)
- **L2.BODY.017** `unproven` A value type not `DTYPE[shape] @SPACE` is refused "a value's type is DTYPE[shape] @SPACE"; a non-constant dimension is refused "a value's shape is constant". (code: ktpu-l2/src/ir/read.rs; evidence: refusals, offline only)
- **L2.BODY.009** `silicon` `instances(body)` walks the body with every `par` and `for` variable bound: each unit `par` is one stage of concurrent instances, each node-scope op one stage. (code: ktpu-l2/src/ir/read.rs; doc: ktpu:382-399; evidence: 455 kernels)
- **L2.BODY.019** `RTL` Inside a node-scope `for ... pipe=K` a stage carries its group (loop, iteration, K); each stage carries its phase (one run of a `par` over nodes). (code: ktpu-l2/src/ir/read.rs; evidence: E/l2/fused/tilesilu.ktpu:9 (`pipe=2`): tl1::test_l2_tiles_drain_into_the_cores_and_overlap; silu2.ktpu:6 (a node phase): test_l2_silu_on_two_nodes)

## 2. Types and spaces

- **L2.SPACE.001** `silicon` A buffer is `DTYPE[dims] @dram`, DTYPE `f16`, `mx7a` or `mx7b`. (code: ktpu-l2/src/ir/buffer.rs; doc: ktpu:339-341; evidence: `@dram` parameters in 455 / 455, every one f16, mx7a or mx7b)
- **L2.SPACE.010** `RTL` A buffer may be `f32`. (code: ktpu-l2/src/ir/buffer.rs; evidence: the lane relayout's fp32 index lists (kernels/lanes.py:131): test_tinygrad.py `narrow_transpose`, `odd_permute`)
- **L2.SPACE.011** `unproven` A buffer may be `@stage`, DTYPE `u8 u32 i32 u64`; leading dimensions are a batch of [M, N] slabs. (code: ktpu-l2/src/ir/buffer.rs; evidence: no `@stage`, integer or batched (rank > 2) buffer in the tally or a cited card test)
- **L2.SPACE.002** `silicon` Layouts: `mx7a` takes `gm=` and `nk=`, `mx7b` `gn=` and `nk=` (tile-major MXFP7, the clusters' A and B packings); `tile=GMxGN` is drained sub-tiles (tiles of GM x GN 4 x 4 sub-tiles, row-major tiles, row-major sub-tiles in one). (code: ktpu-l2/src/ir/buffer.rs; evidence: `mx7a[..] @dram(gm=64, nk=1)`, `mx7b[..] @dram(gn=8, nk=1)`, `@dram(tile=64x8)` in the matmul kernels)
- **L2.SPACE.009** `unproven` `ieee=1` reads a tile layout's values as IEEE fp16 and needs `tile=`; `t=1` holds each slab transposed; `node=N` places a buffer in node N's staging and needs `@stage`; an MXFP7 buffer with keys other than its own (and `t`, `node`) is refused "mx7a wants @dram(gm, nk=...)"; unknown keys are refused "layout keys: gm gn nk tile ieee t node"; a layout other than `node` needs [.., M, N] slabs. (code: ktpu-l2/src/ir/buffer.rs; evidence: none of these in the silicon kernels; offline)
- **L2.SPACE.003** `silicon` `@A` holds `mx7a[M, K]` and `@B` holds `mx7b[N, K]`: M (N) whole groups of `mg.lanes` [4], K whole blocks of `mg.kblock` [32], at most `mg.l1_bank_entries` [256] entries (M/4 x K/32) a value. (code: ktpu-l2/src/lower/cluster.rs; doc: ktpu:342; evidence: fills of 64 and 8 entries in the matmul kernels)
- **L2.SPACE.004** `silicon` `@acc` holds `f32[M, N]`: whole 4 x 4 sub-tiles, at most `mg.tiles` [4096]. (code: ktpu-l2/src/lower/cluster.rs; doc: ktpu:343; evidence: 4471 gemms)
- **L2.SPACE.005** `silicon` `@l1` holds rows of f16 in a core's L1; `@l1(gt4)` 4 x 4 sub-tiles (or GT4 bands read from a row-major buffer); with no cluster draining into it a core's buffers take all `vc.l1_words` [512]. (code: ktpu-l2/src/lower/vector/mod.rs, ktpu-l2/src/lower/mod.rs; doc: ktpu:344; evidence: vunpk f16 8131, gt4 450)
- **L2.SPACE.006** `silicon` `@reg` holds one `vc.vlmax` [128]-value row a register; `@reg(gt4)` one 4-row x 32-column block a register (row i, columns 16q.. in chunk 4q + i); a statistic `f32[R] @reg` of GT4 rows holds one register a 4-row band. (code: ktpu-l2/src/lower/vector/mod.rs; doc: ktpu:345, 375; evidence: 455 kernels: the rows kernels' GT4 bands and statistics (`vmax xor` / `vadd xor` folds))
- **L2.SPACE.012** `unproven` A value of another type in `@A` / `@B` is refused ("@A holds mx7a, not X"); an `@acc` value not of whole sub-tiles or past 4096 is refused ("f32[M, N] @acc: whole 4x4 sub-tiles, at most 4096"). (code: ktpu-l2/src/lower/cluster.rs; evidence: refusals, offline only)
- **L2.SPACE.013** `RTL` A core's buffers sit below the landing ring when clusters drain into its L1. (code: ktpu-l2/src/lower/mod.rs; evidence: E/l2/fused/tilesilu.ktpu (drain into the cores): tl1::test_l2_tiles_drain_into_the_cores_and_overlap)
- **L2.SPACE.014** `RTL` A statistic of plain rows holds 8 rows in chunk 0 a register. (code: ktpu-l2/src/lower/vector/mod.rs; evidence: E/l2/vector/softmax.ktpu, layernorm.ktpu: tl1::test_l2_softmax, test_l2_layernorm)
- **L2.SPACE.015** `unproven` `@l1` holds f32 rows too. (code: ktpu-l2/src/lower/vector/mod.rs; evidence: no f32 `@l1` value in the tally (`vunpk` f16 / gt4 only) or a cited card test)
- **L2.SPACE.007** `unproven` `@mem` leaves DRAM or staging to the space pass; `@any` lets the space pass put a scratch tile straight into the cores' L1. (code: ktpu-l2/src/passes/space.rs; doc: l2p:48, ktpu:346, 476-481; evidence: offline Rust L2 witnesses (`ktpu-l2/tests/ported.rs`))
- **L2.SPACE.008** `silicon` Scratch buffers become parameters of the L1 fn, placed by the caller. (code: ktpu-l2/src/lower/mod.rs; evidence: `h1`.. parameters in the silicon kernels; whether the caller zeroes them: conflict 8)

## 3. Views

- **L2.VIEW.001** `silicon` A view is `NAME[axis, ...]`, each axis `LO : +N` (a run) or `:` (whole); axes left out are whole. (code: ktpu-l2/src/lower/memory.rs; doc: l2p:80-81; evidence: 455 kernels, from the DSL's views (`docs/spec/stack/dsl/graph.md` DSL.VIEW.006))
- **L2.VIEW.004** `unproven` A view axis may be `I` (one index, the axis dropped), `LO : HI` or `*` (a new broadcast axis). (code: ktpu-l2/src/lower/memory.rs; evidence: the generators of the card kernels write runs and wholes only)
- **L2.VIEW.002** `unproven` A view outside its buffer is refused "NAME axis D: [LO, HI) of N"; a non-constant bound after binding is refused "a bound is a constant here"; another axis form is refused "an axis is I, LO : +N, LO : HI or :"; more axes than the buffer has "NAME has N axes". (code: ktpu-l2/src/lower/memory.rs; evidence: offline)
- **L2.VIEW.003** `unproven` A view of a batched buffer picks one slab ("a view picks one slab of a batched buffer"). (code: ktpu-l2/src/lower/memory.rs; evidence: no batched (rank > 2) buffer in the tally; the rule is a refusal)

## 4. Order

- **L2.ORDER.001** `silicon` Within one instance, order is program order; between instances only memory orders: statements after a `par` see everything its instances did. (code: ktpu-l2/src/lower/sync.rs; doc: l2p:85-94; evidence: 455 kernels)
- **L2.ORDER.002** `silicon` Each unit `par` and each run of consecutive node-scope mover ops is a stage; a stage records its accesses: byte ranges of buffers, a core's L1 words, a cluster's entries of both banks of a side, and a cluster's receive port. (code: ktpu-l2/src/lower/sync.rs, ktpu-l2/src/lower/mod.rs; doc: ktpu:382-388; evidence: 455 kernels)
- **L2.ORDER.003** `silicon` Two accesses conflict when they share a key, one writes and their ranges meet -- except that two streamed accesses never conflict, and a unit touching its own memory both times is ordered by its own run. (code: ktpu-l2/src/lower/sync.rs; evidence: 455 kernels)
- **L2.ORDER.004** `silicon` A later stage waits only for the units of earlier, not yet waited stages it conflicts with: `wait UNIT upto=MARK` on a mark placed after that stage, or `wait moves T` for the mover (which covers every earlier move); a mark is printed only when a wait names it. (code: ktpu-l2/src/lower/sync.rs; doc: ktpu:384-388; evidence: `mark` / `wait upto` 7752 / 165)
- **L2.ORDER.005** `silicon` Consecutive node-scope mover ops of one group are one posted move; the last stage of a program, when a move, is a plain `move`; otherwise the program ends with `wait moves` on the last post (if any) and `barrier`. (code: ktpu-l2/src/lower/mod.rs, ktpu-l2/src/lower/sync.rs; doc: ktpu:394-395; evidence: 292 plain moves ending kernels, 163 barriers)
- **L2.ORDER.006** `RTL` Inside a node-scope `for ... pipe=K`, a stage that needs a wait first sends ahead the stages of the next K - 1 iterations that need no wait, share no unit with, are no fence before, and touch nothing written by, the stages they pass. (code: ktpu-l2/src/lower/sync.rs; doc: ktpu:353; evidence: tl1::test_l2_tiles_drain_into_the_cores_and_overlap)
- **L2.ORDER.007** `RTL` A unit-to-unit transfer's reader waits for its landing itself (a COUNT it takes); a wait on the sender only orders the reuse of the landing place. (code: ktpu-l2/src/lower/sync.rs; doc: ktpu:388-390; evidence: tl1::test_l2_mlp_with_nothing_in_memory_between_layers)
- **L2.ORDER.008** `RTL` Across nodes, stages of one phase are not ordered. (code: ktpu-l2/src/lower/mod.rs; doc: ktpu:399-405; evidence: E/l2/multinode/silu2.ktpu, share2.ktpu (one node phase each, no `ring` / `wait slot` emitted): tl1::test_l2_silu_on_two_nodes, test_l2_shared_fills_on_two_nodes)
- **L2.ORDER.009** `unproven` When a stage of a later phase touches memory a stage of an earlier phase on another node wrote (or reads what that one read and this one writes), the earlier node waits its units and rings `ring mesh=B slot=ORDER+A` (ORDER = 0), and the later node waits `wait slot ORDER+A n=1 consume` before it starts. (code: ktpu-l2/src/lower/mod.rs; evidence: no tl1 example has two node phases (`_order_nodes` emits nothing for silu2 / share2))

## 5. Cluster instances (`par ... on mg[E]`)

- **L2.MG.001** `silicon` A cluster instance runs `fill`, `zero`, `gemm` and `drain`. (code: ktpu-l2/src/lower/cluster.rs; doc: ktpu:354-360; evidence: 15 matmul kernels)
- **L2.MG.002** `silicon` `x = fill VIEW : mx7a[M, K] @A | mx7b[N, K] @B` FILLs the view's runs of a tile-major MXFP7 buffer; the view's K is one packed chunk (`nk` x 32, at a multiple of it) and its rows whole lane groups; the view's shape equals the value's. (code: ktpu-l2/src/lower/cluster.rs, ktpu-l2/src/lower/memory.rs; doc: ktpu:354; evidence: `fill A0 <- a+0 n=64` form 8942 in 15 kernels)
- **L2.MG.003** `silicon` A fill takes the bank of its side that holds no value still read and that the latest sweep does not read, alternating from the side's last value. (code: ktpu-l2/src/lower/cluster.rs; doc: l2p:100-102, ktpu:354; evidence: alternating A0 / A1, B0 / B1 in the matmul kernels)
- **L2.MG.016** `unproven` `recv` is a cluster op too (L2.MG.015); any other op is refused "no cluster op 'X': fill, recv, zero, gemm, drain". (code: ktpu-l2/src/lower/cluster.rs; evidence: refusal, offline only)
- **L2.MG.017** `unproven` A fill's `share=` (L2.MG.005); a view whose K is not one packed chunk or whose rows are not whole lane groups is refused "a fill's K is one packed chunk ..."; rows crossing a packed tile are two runs; a view whose shape differs from the value's is refused. (code: ktpu-l2/src/lower/cluster.rs, ktpu-l2/src/lower/memory.rs; evidence: no `share=` or tile-crossing fill in the card kernels; refusals)
- **L2.MG.018** `unproven` A fill with no free bank is refused "both A banks hold values still read". (code: ktpu-l2/src/lower/cluster.rs; evidence: refusal, offline only)
- **L2.MG.004** `silicon` A run of N entries is FILLs of at most `mg.max_fill` [255]: N <= 255 whole, N <= 510 in halves, else 255 at a time. (code: ktpu-l2/src/lower/cluster.rs; evidence: fill counts 64, 76, 60, 42, ... in the tally)
- **L2.MG.005** `RTL` `share=cross` reads once for a group of clusters, one of each memory port in turn, the node the rendezvous: per step each follower gets only its own fills from the leading consecutive FILL prefix, a mark, then the shared fill and the rest in program order. No FILL crosses a GEMM, DRAIN or POST: GEMM retires on issue while its L1 reads continue (ISA.MG.024). Each leader (the lowest {y, x}), once its followers' marks complete, the shared fill with `peers=`. (code: ktpu-l2/src/lower/share.rs, ktpu-l2/src/lower/cluster.rs; doc: ktpu:354; evidence: E/l2/multinode/share2.ktpu:11 `share=cross`: tl1::test_l2_shared_fills_on_two_nodes)
- **L2.MG.019** `unproven` `share=port` groups the clusters on one memory port, `all` every instance; every instance must fill the same shared views in the same order ("share=: every instance fills the same shared views, in the same order") with one mode a par, else refused. (code: ktpu-l2/src/lower/mod.rs; evidence: no tl1 example shares by `port` or `all`; refusals)
- **L2.MG.006** `unproven` A shared B fill of more than `mg.shared_b_max` [64] entries is refused "a shared B fill of N entries: a follower's B entries past 64 come back wrong (Verilated card); fill it unshared". (code: ktpu-l2/src/lower/cluster.rs; doc: ktpu:405-407; evidence: offline)
- **L2.MG.007** `silicon` `c = zero : f32[M, N] @acc` makes the next sweep into c open the tile (`acc=0`); `c = gemm a, b[, c] : f32[M, N] @acc` is one sweep, `acc=1` when it chains into a swept c; a reads an @A value and b an @B value of this cluster with equal `nk`, M = a's rows, N = b's rows. (code: ktpu-l2/src/lower/cluster.rs; doc: ktpu:356; evidence: `gemm ... acc=0` 314 / `acc=1` 4157 in the matmul kernels)
- **L2.MG.020** `unproven` A gemm whose operands are not an @A and an @B value of this cluster, of unequal `nk`, or whose type's M / N differ from the operands' rows is refused. (code: ktpu-l2/src/lower/cluster.rs; evidence: refusals, offline only)
- **L2.MG.008** `unproven` A gemm's K is 32 or a multiple of 32 x `mg.kstep`, else refused "K = N: a sweep takes 1 block or a whole number of 2". (code: ktpu-l2/src/lower/cluster.rs; evidence: offline)
- **L2.MG.009** `unproven` `gemm a[LO : +R, :], b` reads rows LO.. of an operand: the same bank, LO/4 x nk entries further in (`aoff=` / `boff=`); rows must be constants of the instance in whole groups of 4 inside the value ("rows LO +N of M: whole groups of 4 inside"), the columns whole ("a slice of an operand takes rows: X[LO : +R, :]"). (code: ktpu-l2/src/lower/cluster.rs; doc: ktpu:356; evidence: no example or generated kernel slices an operand)
- **L2.MG.010** `silicon` `drain c -> VIEW` writes the tile to an `f16 @dram(tile=)` buffer whose 4 x 4 sub-tiles, row-major over the view, are one run; it becomes the last sweep's `emit=` plus a fused DRAIN placed just before the unit's next emitting sweep (or last). - **L2.REL.006** `RTL` `forms.relayout` plans a walk pair with `kernels.relayout` first, one kernel a relayout: the pair's axes `(count, source stride, destination stride)` of count > 1, by destination stride, adjacent axes both walks step as one merged. A source window past the buffer reads a staged copy of the table whole lines in (one buffer a table; the margin words are read only into lanes no segment selects). A word walk (a whole-word part) writes whole lines, or is the one move (at most 16384 words, ISA.MV.007) writing its partial lines; a long fill starts on a line. (code: K/kernels/relayout.py `segments`, `layers`, `runs`, `_emit_runs`, `_program`; evidence: as L2.REL.006; the mutants `rotation direction`, `one layer`, `no margin`, `unstaged copy rows` of test_relayout.py are each caught)
- **L2.REL.008** `RTL` The destination port starts at its memory line (`forms.relayout` moves it back, the elements before it kept) and spans whole lines; of `[z0, m)` the elements no walk reaches are 0 (one mover fill of those words first when any is), every other element of the port kept; with `keep` all are kept. - **L2.REL.015** `RTL` A transpose whose destination rows (each `dB` apart, starting on a memory line) are followed up to whole lines by elements of the zero range that no other element takes writes those rows whole. `tx` is filled with zeros first and its rows extended to the line, so the exchange's rows carry the zeros. (code: K/kernels/relayout.py `_extend`, `_transpose`; evidence: test_relayout.py `transpose_padded_rows` (offline exact, form: no runs, no destination fill; on the model), mutant `unfilled exchange padding` caught; ViT's v^T into rows 224 apart: 130,999 model cycles, against 441,988 + 122,323 dense then padded)
- **L2.REL.016** `RTL` Pull: a broadcast of at most `vc.lanes` copies (values repeated inside a word, `relayout.PULL_RUN`). Slot t of a word holds the word's t-th source word, in first-lane order. Each slot is staged by the mover at its destination word: one word walk of at most `mover.levels` levels when the slots' word sequence is one (`relayout.word_levels`), else a word gather by an fp32 index list. One vector-core program then takes each lane from `xrot(slot t, k)` where the lane's code (a mask-table row a vector row) is `t * 16 + k`, k = (source lane - lane) mod 16. A lane coded ZERO takes 0; a lane coded KEEP (outside the zero range, or with `keep`) takes the destination's lane, staged first. The rows go back by one word walk of whole lines. (code: K/kernels/relayout.py `_pull`, `word_levels`, `pull_rotation`, `_emit_pull`, `_x_pull`; evidence: test_relayout.py `pull_upsample`, `pull_keep`, `pull_zero_range`, `splat_pairs`, `splat_lane_copies` offline exact and compiled, on the model; mutants `pull rotation reversed`, `pull second source unstaged`, `pull kept lanes zeroed` caught. - **L2.REL.014** `RTL` A relayout is bit-exact but for two values an element passing vector-core math changes: a NaN stays NaN without its payload, and -0 comes back +0. On the card model every vector-core math op (`sel` against a vector or a constant, `xrot`, `xlane`, `mul` by 1, `add` of 0) gives +0 for -0 (0x8000); unpack then pack alone keeps it, and so does a mover move (whole-word walks, copy-class rows). (code: K/kernels/relayout.py `_program`, `_emit_splat`, `_emit_shuffle`; K/kernels/transpose.py `emit`; evidence: test_relayout.py `test_relayout_on_the_card_is_exact` (every f16 bit pattern, -0 accepted as +0 only))

### Relayout prologues

`relayout.emit_steps` embeds planned relayouts in a consumer kernel. Scratch
buffers retain the transform grain and line ownership of standalone relayouts;
index and mask tables are explicit input ports. `prepared.rows_kernel` emits
one preparation for aliased readers, preserving each reader's offset.
Quant-side preparation is disabled (`forms.PREPARED_QUANT=False`); packing
receives materialized inputs. Device-side nonfinite checking remains the
packing backend's contract; rows preparation does not assert that arbitrary
inputs are finite.

## 11. Passes

- **L2.PASS.001** `silicon` `compile_l1` runs the passes `select, place, space, share, split, step, pipeline, retile, stage` in that order (`stage`: a gather, scatter or copy whose two sides both step one-word runs goes through a contiguous scratch on a machine whose `mover.one_word_runs` is false, F-001); each prints L2 text with its choice written in, and the text is read back (re-verified by the reader) before the next; then the lowering, then the image scheduler; the machine's `vc.regs` / `vc.rf_copies` become the module's. (code: ktpu-l2/src/lib.rs, ktpu-l2/src/passes/mod.rs; doc: l2p:51-52; evidence: every silicon kernel)
- **L2.PASS.002** `RTL` `select`: `o = sel m, x, s` where m is `cmpgt x, 0.0` and `s = mul x, a` (0 <= a <= 1) becomes `max x, s`; the compare, read by nothing else, is dropped. The values equal the select's bit for bit. (code: ktpu-l2/src/passes/select.rs; evidence: E/l2/vector/leaky.ktpu (`cmpgt v, 0.0`, `s = mul v, 0.1`, `sel`), compiled to `mul`, `max`: tl1::test_l2_compare_and_select)
- **L2.PASS.012** `unproven` Compilation requires the named machine schema; there is no default board. (code: ktpu-l2/src/lib.rs; evidence: the card and the tests pass a machine (`software/compiler/kohakutpu/stack/kernel.py`, test_l1_examples.py:255))
- **L2.PASS.013** `unproven` The select pass's other forms: the arm for x > 0 being s with a > 1 (`max`), the remaining cases (`min x, s`), a mirrored compare `cmplt 0, x`, and a compare kept because something else reads it. (code: ktpu-l2/src/passes/select.rs; evidence: leaky takes the `max` branch only)
- **L2.PASS.003** `unproven` `place`: `par v in LO..HI on mg[any]` / `vc[any]` puts instance i on unit (v - LO), taken mod the machine's count when the instances outnumber the units (or the count is not constant); another kind with `[any]` is refused "KIND[any] is not a unit kind"; a placement on a unit kind the machine has none of is refused with L2.PASS.003, "KIND[any]: this machine has no KIND units". (code: ktpu-l2/src/passes/place.rs; evidence: offline (`L2.PASS.003.absent_kind`, sru_v9t7))
- **L2.PASS.004** `unproven` `space`: an `@any` scratch tile the clusters of one `par` drain and only the cores of the next `par` read back, a band of whole tile rows a trip, becomes `drain c -> vc[..]` and `recv` when every core reads exactly one cluster's tile and it fits the stack's 256-word landing pool; otherwise `@mem` / `@any` becomes `@stage` when it fits the stack's staging room (1 MB, half the `die.staging.entries` x `die.staging.entry_words` words of the staging store), else `@dram`. (code: ktpu-l2/src/passes/space.rs; doc: ktpu:476-481; evidence: offline (`anysilu`))
- **L2.PASS.005** `unproven` `share`: in a body over several nodes, a cluster fill whose view does not name the cluster's `par` variable becomes `share=cross`, except a B fill past `mg.shared_b_max` [64] entries; a body over one node is unchanged. (code: ktpu-l2/src/passes/share.rs; doc: ktpu:442-443; evidence: E/l2/multinode/share2.ktpu:11 already writes `share=cross`, which the pass skips (ktpu-l2/src/passes/share.rs), so tl1::test_l2_shared_fills_on_two_nodes witnesses no rewrite)
- **L2.PASS.006** `unproven` `split`: `c = gemm a, b[, c] split` after its two fills becomes a loop over K in chunks of the operands' packing (`nk` x 32), fills and sweep inside, a `zero` before when no accumulator is named; refused when not after its two fills, when K is not several chunks, or when one chunk still overflows a bank. (code: ktpu-l2/src/passes/split.rs; doc: ktpu:444; evidence: offline)
- **L2.PASS.007** `unproven` `step`: a vector stream loop some memory view of which steps further a trip than the signed `vc.ainc_bits` range becomes a node-scope loop around its `par`, one trip a run (`for t in T..T + 1` inside); trips depending on the instance span every instance's, each instance's kept by `when T >= LO` / `when T < HI`; a loop whose trips carry values, or with statements after it, is refused "a stream loop stepping N bytes a trip (ainc reaches 131071) carries values from trip to trip". (code: ktpu-l2/src/passes/step.rs; doc: ktpu:444-450; evidence: offline)
- **L2.PASS.008** `unproven` `pipeline`: a node-scope `for` (outside every unit `par`) whose body runs pars of two unit kinds gets `pipe=2`; when the body's first `par` runs on units a later `par` also runs on, the loop is rotated -- that `par` of iteration i + 1 ahead of the rest of iteration i -- where no memory view of it meets one of the pars it passes (one writing); a loop already piped is left. (code: ktpu-l2/src/passes/pipeline.rs; doc: ktpu:450-454; evidence: `tilesilu.ktpu:9` and `mmsoftmax` already write `pipe=2`, which the pass skips (ktpu-l2/src/passes/pipeline.rs); no tl1 example has a node-scope loop without `pipe=`)
- **L2.PASS.009** `silicon` `retile`: for each vector stream loop of R rows a trip (every op but the loop-invariant ones R rows, views stepping VAR x R), of the multiples 1, 1/4, 1/2, 2, 4 of R and every whole band dividing R (bands of 4 rows for GT4, 1 otherwise), the tile that lowers and that the issue model times fastest over all its trips is kept only when 2% better than the best before it (the written tile first); both trip bounds scale by R / new; a `par` inside node-scope loops is costed at their first iteration and first instance. (code: ktpu-l2/src/passes/retile.rs; doc: ktpu:454-466; evidence: every silicon vector kernel)
- **L2.PASS.010** `unproven` When no tile lowers, a stream whose ops each work on 32-column GT4 blocks apart splits its columns into the fewest equal pieces one of which lowers (found by bisection), a `par` a piece with its values renamed `NAME_j`; else the pass refuses "no row tile of the stream lowers: REASON" with the written tile's reason. (code: ktpu-l2/src/passes/retile.rs; doc: ktpu:461-464; evidence: offline)
- **L2.PASS.011** `silicon` No pass changes what is computed: each narrows a choice the body left open and its output is read back and verified. (code: ktpu-l2/src/passes/mod.rs; doc: l2p:51-52; evidence: the silicon kernels' card results)

## 12. Candidate search and determinism

- **L2.SEARCH.001** `silicon` A vector instance's image is the fastest under `ktpu-l1::sched::timing` of its candidates: every band shape (1, 2, 4, 8, 16 row groups at once) x re-unpack after a reduction or hold x next band's unpacks ahead or not x (with more than 14 constants) held or staged x (with rows unpacked before the loop) pinned or unpacked again, plus the modulo schedule; the first by cycles that encodes within the stack's image room (1000 IMEM words) wins, ties keeping the order tried. (code: ktpu-l2/src/lower/vector/mod.rs; doc: ktpu:418, 466-471; evidence: every silicon vector image)
- **L2.SEARCH.002** `silicon` `ktpu-l1::sched::timing` prices an image by the replay bench's rules: in-order front end a word a cycle (an op's configuration words before it; `vsync`, `seti`, `setvl`, `halt` two cycles), engine queues of `vc.queue_depth` / `vc.dma_queue_depth`, a math op a beat a 16-lane chunk (held a beat where a two-copy file reads three words of one bank), an unpack or pack a word a cycle, one memory port a core priced by `vc.fill_alone` / `vc.fill_shared`, the latencies LAT_MM 20, LAT_XB +7, LAT_UM 12, LAT_MP 20; a loop runs 4 passes and the rest at the last pass's cycles. (code: ktpu-l1/src/sched/timing.rs, ktpu-l2/src/lower/vector/modulo.rs; doc: ktpu:416-418; evidence: the search behind every silicon image)
- **L2.SEARCH.003** `unproven` A body whose vector stage shares a node loop with a cluster stage, or lives in a loop with drains into the cores, is priced with `vc.fill_shared` (330, 5), else `vc.fill_alone` (78, 2); the modulo schedule issues an iteration's fills that latency plus its words' cycles ahead of its first unpack. The costs are measured on the Verilated card_v9t3_1n. (code: ktpu-l2/src/lower/mod.rs, ktpu-l2/src/lower/vector/modulo.rs, ktpu-l2/src/target.rs; doc: ktpu:431-439; evidence: model figures, no v9t6 measurement)
- **L2.SEARCH.004** `silicon` The search and the lowering are deterministic: the same L2 text, machine and compiler source give the same L1 text; a candidate shape seen before (keyed by one candidate's image, the L1 landing, `vc.regs`, `vc.rf_copies`, the fill cost, the strategy and the IMEM room) is not searched again. (code: ktpu-l2/src/lower/vector/mod.rs; evidence: compiles keyed by text, software/compiler/kohakutpu/stack/kernel.py)
- **L2.SEARCH.005** `unproven` The Python seam keeps 1024 compiled kernels in memory by source, machine and options. Rust stage caches (`build/compile`, or `KTPU_COMPILE_CACHE`, empty for none) key each result by input, machine and the stage's transitive Rust source version; `KTPU_DUMP` keeps each kernel's L2 and L1 text. (code: software/compiler/kohakutpu/stack/kernel.py; ktpu-cache/src/lib.rs; evidence: offline)
- **L2.SEARCH.006** `silicon` Register-file bank placement (`banks.rotate`) places compiled values to avoid three-words-of-one-bank reads at `vc.rf_copies`; it changes cycles, never values. A value written under a predicate (`if=` / `unless=`) keeps rotation 0: the core takes a predicated write's lane mask by its destination chunk (`v2_lanes.v:332`) and a compare writes the mask at its own, unrotated chunk (`:404`), so the destination's rotation must equal the predicate's, which is 0. (code: ktpu-l2/src/lower/vector/mod.rs, ktpu-l2/src/lower/vector/banks.rs `_predicated_dests`; doc: docs/projects/kohakutpu/verify.md:405-416; evidence: every silicon vector image; `L2.SEARCH.006.predicated_unrotated`, TG.FLT.003.card_bools on one core; F-041)

## 13. Lowering to L1

- **L2.LOW.001** `silicon` `lower` writes L1 text: the module's `target` line, the images, then `fn NAME.l1(params)` with the L2 parameters and the scratch buffers; it is read back by the L1 reader. (code: ktpu-l2/src/lower/mod.rs; doc: l2p:110-114; evidence: 455 kernels)
- **L2.LOW.002** `silicon` One `par` runs one unit kind. (code: ktpu-l2/src/lower/mod.rs; evidence: 455 kernels)
- **L2.LOW.012** `unproven` A `par` of several unit kinds is refused ("one par runs one unit kind"); a `[any]` left for the lowering is refused "KIND[any] is the place pass's to resolve first"; a `par` on a kind with no lowering is refused "L2 -> L1 has no KIND lowering yet". (code: ktpu-l2/src/lower/mod.rs; evidence: refusals, offline only)
- **L2.LOW.003** `silicon` A vector stage is `send vc[i]` / `run IMG(args)` per instance; every memory descriptor's base is an image parameter (`desc aK = p_aK`) its `run` binds (`BUF+OFF`), so the instances of one shape share one image text. (code: ktpu-l2/src/lower/mod.rs, ktpu-l2/src/lower/vector/mod.rs; doc: ktpu:151-155; evidence: `run` 8109 of 381 images)
- **L2.LOW.004** `silicon` A cluster stage's instances on one unit merge into one stream, banks carried across; the stage's lines are each unit's words segment by segment (the outermost `for` iterations), the units in turn. (code: ktpu-l2/src/lower/mod.rs; doc: ktpu:382-394; evidence: interleaved `send mg[0]` / `send mg[1]` in the matmul kernels)
- **L2.LOW.005** `RTL` A transfer lands where `Links` allocates it: into a core, a ring over the top 256 words (the stack's landing pool); into a cluster, a bank, alternating; each `recv` takes the oldest transfer from that sender. (code: ktpu-l2/src/lower/mod.rs; doc: ktpu:355-366; evidence: E/l2/fused/mlpdirect.ktpu (256 words into a core, 32 entries into a bank): tl1::test_l2_mlp_with_nothing_in_memory_between_layers)
- **L2.LOW.013** `unproven` A transfer of more than 256 words into a core is refused "N words into vc[H]: a core takes 256 at a time"; more than a bank into a cluster is refused; a `recv` with no earlier transfer is refused ("recv: SRC sent nothing into DST (SIDE) before this"); a transfer nothing receives is refused "SRC sends into DST (SIDE) that nothing receives". (code: ktpu-l2/src/lower/mod.rs; evidence: refusals, offline only)
- **L2.LOW.006** `unproven` A pair whose receiver takes inside a loop is a stream with a ring of two receiver transfers (into a core, 2 x tile words at the top of its L1, at most the stack's 256-word landing pool, else "two of these tiles exceed 256 words"; into a cluster, from entry 0, at most both banks, else "two of these tiles exceed a side's banks"); stream transfers must be whole, in order and not split ("recv of N splits SRC's transfer into DST"). (code: ktpu-l2/src/lower/mod.rs; doc: ktpu:355, 363, 487; evidence: no tl1 example's receiver takes inside a loop (`_streams`, ktpu-l2/src/lower/mod.rs), so no stream ring is built)
- **L2.LOW.014** `unproven` Each stream into a core: at the program's start the core's open image posts the whole ring to the sender (`vpost`, one per credit word of at most `CREDIT_WORD` [512] credits); at its end the sending cluster spends the last lap's credits by one `credit` drain into the ring per credit word, `drain n=C to=vc[H] l1=LO credit` with C that word's count, never more than the ring's credits (a `credit` drain past the credits held waits for credits nothing returns, `mx_cluster_cu.v:1073-1095`). (code: ktpu-l2/src/lower/mod.rs; ktpu-l2 `lower/mod.rs` `open`, `spend`; evidence: offline, `L2.LOW.014.spend_192` (a 192-word ring); F-039)
- **L2.LOW.007** `unproven` One POST / VPOST / VWAIT word carries at most 512 credits; a credit is a 32-byte granule; credit-spending drains are at most 128 granules. (code: ktpu-l2/src/lower/mod.rs, ktpu-l2/src/lower/cluster.rs; evidence: credits are spent only by streams, which no tl1 example builds)
- **L2.LOW.008** `unproven` Consecutive stages joined by a stream are sent as one: the cores' RUNs first, then the clusters' segments interleaved by progress (each next from the stage least far through its own). (code: ktpu-l2/src/lower/mod.rs; doc: ktpu:391-393; evidence: the grouping needs a stream, which no tl1 example builds)
- **L2.LOW.009** `RTL` A `par` over nodes gives each node its own `node N` block; the nodes share memory. (code: ktpu-l2/src/lower/mod.rs; doc: ktpu:352, 399-401; evidence: tl1::test_l2_silu_on_two_nodes)
- **L2.LOW.010** `unproven` A vector store of loaded L1 bytes (no unpack / pack) orders the next fill behind its drain and its drain behind its fill (`vsync fill on=drain`, `vsync drain on=fill`). (code: ktpu-l2/src/lower/vector/mod.rs; doc: ktpu:407-409; evidence: no card test is known to store loaded bytes; the tally holds `vsync drain on=fill` 13 / 11 and `vsync fill on=drain` 2 / 2, not traced to this rule)
- **L2.LOW.011** `RTL` The compiled L1 computes what the L2 body computes: the L2 examples compiled through `compile_l1` match numpy on a Verilated card. (code: ktpu-l2/src/lib.rs; doc: l2p:113-115; evidence: tl1::test_l2_silu, test_l2_add, test_l2_softmax, test_l2_layernorm, test_l2_split_k, test_l2_matmul_then_silu_through_gt4, test_l2_mlp_quantises_its_activation_on_the_core, test_l2_softmax_of_scores_never_in_memory)

## 14. Not in L2

- **L2.REF.001** `unproven` A `for` inside a vector stream loop, a vector value carried from one stage to the next, any run-time condition other than `sticky`, and the `send` direction of `@any` are not L2: they are refused or written out. (code: ktpu-l2/src/lower/vector/mod.rs, ktpu-l2/src/ir/read.rs, ktpu-l2/src/passes/space.rs; doc: ktpu:483-487; evidence: the refusals offline; `sticky` on the card: tl1::test_l2_sticky_softmax_on_both_paths)
- **L2.REF.002** `unproven` The GT4 values of one stream loop have one width, a multiple of 32, beside 32-wide band values ("GT4 values of one width, a multiple of 32"); its row values one register count ("one register count in the stream loop, got [...]"), the tile splitting into the group size ("N rows do not split into groups of G"). (code: ktpu-l2/src/lower/vector/mod.rs; evidence: offline)
- **L2.REF.003** `unproven` A value name not made before its use is refused "no value NAME"; a value of the wrong kind "NAME is a KIND value, not KIND". (code: ktpu-l2/src/lower/vector/mod.rs; evidence: offline)

## Class-fixed lowering

These Rust lowering modes are offline compilation choices, not a value-correctness certification. Generated packages with node register control are not dispatch-engine packages (L0.BIND.014).

- **L2.CLASS.001** `unproven` `par ... classed=1` keeps the requested core set, single-buffer serial-band planning and image structure. VSETI-bound loop counts feed VLOOP, with a zero-trip VSKIPZ guard. Register widths come from the shape class; CHKVL masks valid columns. The all-core and minimum-core policies are distinct compile-time choices. (code: software/rust/crates/ktpu-l2/src/lower/vector/ctx.rs; witnesses: software/application/tests/kernels/test_class_rows.py, `l2.class/no-idle`, `l2.class/no-mask`)
- **L2.CLASS.002** `unproven` A reduction marked `carry=1` accumulates successive column trips into a pinned f32 band accumulator, initialized before the single VC loop. Repeated row bands use separate node dispatches, not nested VC loops. A tiled class input must be stacked tile rows for an affine descriptor increment. (code: software/rust/crates/ktpu-l2/src/lower/vector/ctx/reduce.rs; witnesses: software/application/tests/kernels/test_class_fold.py, `l2.class/carry-init`)
- **L2.CLASS.003** `unproven` `copy ... node_loop=1 classed=1` keeps matched walk axes and emits a bounded inner move inside fixed node counters. `node_loop=2` emits a one-word move with mixed-radix source/destination offsets and supports different ranks with equal word counts. `quant` and `gt4` with `node_loop=1` iterate converted entries, retaining the transform's fixed entry shape. Counters, strides and bounds are value fields; address changes use L1.MOV.018. Nested entry loops support at most eight axes so counters cannot alias reserved delta/scratch registers. (code: software/rust/crates/ktpu-l2/src/lower/mover.rs; witnesses: software/application/tests/kernels/test_class_moves.py, `l0.program/advance-replace`, `l2.mover/unchecked-class-depth`)
- **L2.CLASS.004** `unproven` `gemm_tiles DST <- A rhs=B batches=BT rows=M cols=N clusters=C shared=0|1` reads whole packed mx7a/mx7b buffers and writes stacked f16 tiles. The packing fixes GM, GN and NK; M/N/K and batches bind node-loop counts. Each tile starts with `acc=0`, later K chunks with `acc=1`; an idle POST precedes bank reuse. Requested clusters without a tile skip their body. (code: software/rust/crates/ktpu-l2/src/lower/cluster/tiles.rs; witnesses: software/application/tests/kernels/test_class_mm.py, `l2.cluster/no-idle-post`)
