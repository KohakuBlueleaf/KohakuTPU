# L0 boot block

What the host tells a sysnode's firmware before it starts: the block at the base
of the sysnode's scratchpad, its fields and flags, the unit table (given or found
by the firmware), and the memory the firmware may use. The firmware copy is
`software/kohakuaccel/firmware/include/ka/boot/args.h` and `boot/args.c`; the
host copy is `software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py`
(`BootArgs`), placed by `boot/loader.py` (`NodeBoot`).

**What the card ran.** The 2026-10-21 v9t6 runtime booted sysnode 0 with
`BootArgs(queue = the staging queue's address, mesh = 0, scan = grid_hi + 1,
flags = TIMING)` plus `STEPS` on request, `timeout` = the host's wait seconds ×
the sysnode clock when the clock was given (the logged runs `lenet_n1*.log` ran
with the 2,000,000-cycle default), `cq_depth` 0 and an empty unit
table, so the firmware enumerated its own units
(software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:252-309, :358). A given
unit table, a nonzero `cq_depth`, the flags `SERIAL`, `NOFETCH`, `NOENGINE`
and every refusal were not exercised there.

**Version 3.** The block contains 37 words, including the region table at words 25–36. CARD1 is a reported run, not a recorded image build or ABI-section dump; see L0.BOOT.027.

## Placement

- **L0.BOOT.001** `unproven` The block is 37 little-endian 64-bit words (296 bytes) at the base of the sysnode's scratchpad, `node.spad_base` [0x1_0000] (the load window's region 1, offset 0). The firmware image reserves the space as its first scratchpad section, zero-filled. (code: software/kohakuaccel/firmware/boot/args.c:6; software/kohakuaccel/firmware/arch/rv64/node.ld:20-23; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py:11-15,30-32; doc: docs/spec/node-queue.md:49-52; evidence: af7c1bb:software/driver/kohakuaccel/driver/node/boot/args.py:11-29 defines the version-2 block; current 37-word image provenance is not established by CARD1)
- **L0.BOOT.002** `unproven` `NodeBoot.load` validates available image ABI words before stopping the core, but permits an image with no ABI section. It stops the core, loads the image, writes the boot block and boots. The card runtime separately requires an ABI section. (code: software/kohakuaccel/driver/kohakuaccel/driver/node/boot/abi.py:56-69; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/loader.py:49-72; software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:322-358; evidence: af7c1bb:software/firmware/kohakuaccel/apps/dispatcher/main.c:1-39 declares no ABI section; CARD1 image-section contents are not recorded.)
- **L0.BOOT.003** `unproven` To restart sysnodes whose memories survived reset, the card runtime stops each core, reinitializes its queue and forgets its runtime resident state, then calls NodeBoot.restart. That loader validates available image ABI words, stops the core again, restores scratchpad file bytes and the boot block, and boots the image already in instruction memory. (code: software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:437-446; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/loader.py:74-87)

## Fields

- **L0.BOOT.004** `unproven` Words in order: 0 magic `0x31544F4F42414B` ("KABOOT1"), 1 version `3` (`fw.boot.version`), 2 `queue`, 3 `mesh`, 4 `scan`, 5 `timeout`, 6 `cq_depth`, 7 `flags`, 8 `nunits`, 9-24 the unit table (`fw.max_units` [16] unit words, unused ones 0), 25-36 the region table (L0.BOOT.026). (code: software/kohakuaccel/firmware/include/ka/boot/args.h:8-57; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py:11-15,30-31,96-111; doc: docs/spec/node-queue.md:54-66; evidence: af7c1bb:software/driver/kohakuaccel/driver/node/boot/args.py:11-29 defines version 2; current version 3 and region words lack a recorded card image identity)
- **L0.BOOT.026** `unproven` The region table is `fw.boot.regions` [4] entries of three words, entry `i` at words `25 + 3i`: `base` (unit-global byte address), `size` (bytes), `use` (`fw.boot.region_uses`: 1 `DEBUG`, the debug image's record region; 2 `QUEUE`, the sysnode's queue rings and host-owned package staging; 0 an empty entry). The host fills entries in order and zeroes the rest; `BootArgs.pack` refuses (`ValueError`) more than 4 entries, an entry of use 0, a size of 0 or less, a negative base or an exclusive end at or above 2^64, two entries of one use or of overlapping extents, and a `QUEUE` entry whose base is not the `queue` word. `ka_boot_check` refuses (`KA_BOOT_ERR_REGIONS`) a used entry of size 0 or one that wraps, and two used entries of one use or of overlapping extents. `ka_boot_region(use, &size)` returns the base of the first entry of that use with a nonzero size, or 0 when there is none. The card runtime gives every sysnode one `QUEUE` entry, its queue region, and under debug a `DEBUG` entry; the queue service exits `KA_EXIT_BOOTARGS | KA_BOOT_ERR_QUEUE` unless the `QUEUE` entry's base is the `queue` word, it is at least `0x440` bytes and its base is line-aligned. The debug image reads its `DEBUG` region (RUL.081). (code: software/kohakuaccel/firmware/include/ka/boot/args.h:11-16, :52-60; software/kohakuaccel/firmware/boot/args.c:30-56; software/kohakuaccel/firmware/queue/service.c:170-202, :291-296; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py:76-118; software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:341-357; software/kohakuaccel/firmware/package/debug.c:20-36; evidence: `CARD1`, the debug image's records read from its `DEBUG` region on the card; the `QUEUE` entry and the refusals have no card run)
- **L0.BOOT.027** `unproven` A dispatcher image declares six words in non-loaded `.ka_abi`: boot magic, boot version, debug feature bits (STEPS=1, FAIL=2, LAST=4), completion words kept per unit, queue version and package feature bits. Production debug fields are zero; queue version is `fw.queue.version` [4] and package features are 1. The reader defaults absent queue and feature words to 3 and 0. A .ka_abi section of at least 32 bytes with wrong magic or boot version raises AbiMismatch during the loader ABI check, before that loader stops the core. Missing or shorter sections are treated as absent and permitted by the low-level loader. The card runtime requires the section, requires feature bit 0 for conversion version at least 2, and requires debug features for a debug load; it selects the image’s queue version. (code: software/kohakuaccel/firmware/apps/dispatcher/main.c:12-22; software/kohakuaccel/firmware/arch/rv64/node.ld:58-59; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/abi.py:23-69; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/loader.py:55-59, :79-81; software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:322-339; evidence: docs/spec/stack/debug/firmware.md:24-27 reports CARD1 and external logs but supplies neither image build identity nor ABI-section dump. af7c1bb:software/firmware/kohakuaccel/apps/dispatcher/main.c:1-39 declares no ABI section. Which ABI words CARD1 images carried is not established.)
- **L0.BOOT.005** `silicon` `queue` is the unit-global address of the sysnode's queue region ([node-queue.md](node-queue.md)). (code: software/kohakuaccel/firmware/queue/service.c:173-175, :203; doc: docs/spec/node-queue.md:58; evidence: every card boot)
- **L0.BOOT.006** `silicon` `mesh` is the sysnode's mesh index: the firmware writes it into every unit word it enumerates and compares every package unit's mesh with it. (code: software/kohakuaccel/firmware/apps/dispatcher/main.c:46; software/kohakuaccel/firmware/unit/enumerate.c:64; software/kohakuaccel/firmware/package/interp.c:1826; doc: docs/spec/node-queue.md:59; evidence: every card boot (mesh 0))
- **L0.BOOT.023** `unproven` A package unit of another mesh is foreign ([package.md](package.md) L0.PKG.022). (code: software/kohakuaccel/firmware/package/interp.c:1826-1828; evidence: every card package unit is on mesh 0)
- **L0.BOOT.007** `unproven` timeout supplies the default wait budget in sysnode cycles. Mover and dispatch-engine waits restart it on progress, so it is not a total-duration bound. Failure quiescence bounds its outstanding-work drain by this timeout, then discards mailbox entries without a separate timeout. BootArgs requires timeout as a keyword argument without a default. The card runtime converts seconds using the active sysnode frequency. (code: software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py:35-46,54-69; software/kohakuaccel/firmware/package/interp.c:494-518, :644-650, :1795; software/kohakuaccel/firmware/dispatch/engine.c:383-395; software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:300-306)
- **L0.BOOT.024** `unproven` A `RUN` entry's nonzero timeout replaces the boot block's; the boot timeout also bounds a full stdout ring's wait; the card runtime always writes `bound(seconds, sys MHz)`: `seconds` the given `wait_seconds`, else a third of the host's wait timeout (`firmware_wait_seconds`), and the clock the given `sys_hz`, else the board's idle profile's sysnode clock. (code: software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:261-266, :300-306; software/kohakutpu/application/kohakutpu/application/runtime/card/common.py:125-127; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py:35-40; software/kohakuaccel/firmware/package/interp.c:1795; software/kohakuaccel/firmware/queue/service.c:65-69; doc: docs/spec/node-queue.md:61; evidence: every card `RUN` carried timeout 0; the card ran af7c1bb:software/application/kohakutpu/application/runtime/card.py:222-225, which wrote the host's wait seconds × `sys_hz` only when `sys_hz` was given; no recorded card log shows a scaled bound (LOG:89 shows the 2,000,000 default); the only record of the scaled watchdog is a working note, not a log)
- **L0.BOOT.008** `silicon` `cq_depth` 0 sets no sysnode-wide bound on outstanding completions. (code: software/kohakuaccel/firmware/package/interp.c:1787-1788; doc: docs/spec/node-queue.md:62; evidence: every card boot)
- **L0.BOOT.009** `unproven` A nonzero boot `cq_depth` is truncated to a 32-bit cap. After header validation the package cap is `cap - ack_reserve` when reserve is smaller, otherwise 1. The mailbox path enforces aggregate credit; engine paths do not impose the same aggregate bound. (code: software/kohakuaccel/firmware/package/interp.c:1787-1788, :1815-1822, :755-795; software/kohakuaccel/firmware/dispatch/engine.c:240-242, :314-323; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)

## Flags (word 7)

- **L0.BOOT.010** `unproven` Bit 1 `TIMING`: after each run the firmware prints `PKGT head H copy C bind B steps S barrier E local L total T first F last A sent N idle I`, the phase cycles of that run and the idle before it (L0.NQ.055). The card runtime sets it for a sysnode only when that sysnode's `boot_flags` entry, else its `KOHAKUTPU_BOOT_FLAGS` value, names it; a run's timing otherwise comes in its run record (L0.NQ.056). (code: software/kohakuaccel/firmware/include/ka/boot/args.h:31; software/kohakuaccel/firmware/package/interp.c:1961-1965; software/kohakutpu/application/kohakutpu/application/runtime/card/__init__.py:92, :252-260; software/kohakutpu/application/kohakutpu/application/runtime/card/common.py:47-58, :107-122; doc: docs/spec/node-queue.md:63; evidence: every card run's `PKGT` line, printed by af7c1bb:software/firmware/kohakuaccel/package/interp.c:1583-1586 without `idle`, with `TIMING` always set by af7c1bb:software/application/kohakutpu/application/runtime/card.py:193-197)
- **L0.BOOT.011** `unproven` In the production image, bit 3 `STEPS`: after each step (or round-robin run of steps) the firmware prints `PKGS first last cycles`, the cycles since the steps began with the printing excluded. (code: software/kohakuaccel/firmware/package/interp.c:1838-1843, :1868-1876; doc: docs/spec/node-queue.md:63; evidence: the runtime sets it only on request; no recorded card run names it)
- **L0.BOOT.012** `unproven` Bit 0 `SERIAL` sends each `DISPATCH` step whole instead of round-robin; bit 2 `NOFETCH` ignores every fetch port and sends every word through the mailbox; bit 4 `NOENGINE` runs every package on the firmware path. (code: software/kohakuaccel/firmware/include/ka/boot/args.h:27-37; software/kohakuaccel/firmware/package/interp.c:116, :1030-1031, :1821, :1837; doc: docs/spec/node-queue.md:63)

## Checks

- **L0.BOOT.013** `unproven` Boot validation checks magic, `fw.boot.version` [3], and `fw.max_units` [16], then populated region sizes, unsigned extent wrap, duplicate uses and overlaps, reporting the first error. The dispatcher exits on failure before enumeration or queue service. (code: software/kohakuaccel/firmware/boot/args.c:10-45; software/kohakuaccel/firmware/apps/dispatcher/main.c:38-44; evidence: af7c1bb:software/firmware/kohakuaccel/apps/dispatcher/main.c:21-27 invokes boot validation; current region checks are not established by a recorded card image identity.)
- **L0.BOOT.014** `unproven` A wrong magic, a wrong version or more than 16 units makes the firmware print the reason to the console and exit with `KA_EXIT_BOOTARGS | reason` (`0xE100_0000_0000_0000 |` 1, 2 or 3). The host's `BootArgs.pack` refuses more than 16 units with `ValueError`. (code: software/kohakuaccel/firmware/boot/args.c:13-26; software/kohakuaccel/firmware/include/ka/hal/cpu.h:37; software/kohakuaccel/driver/kohakuaccel/driver/node/boot/args.py:79-82)
- **L0.BOOT.015** `unproven` The other exit words: `KA_EXIT_BOOTARGS | 0x10` for a queue region the firmware refuses, `KA_EXIT_STOP | value` (`0x5701_0000_0000_0000 |` the low 32 bits) after `STOP`, `KA_EXIT_TRAP | mcause` (`0xE000...`) on a trap, `KA_EXIT_STACK` (`0xE200...`) on a task stack overrun. (code: software/kohakuaccel/firmware/include/ka/hal/cpu.h:35-38; software/kohakuaccel/firmware/include/ka/os/task.h:66-67; software/kohakuaccel/firmware/queue/service.c:293-296, :371)

## The unit table

- **L0.BOOT.016** `unproven` When the boot unit list is empty and scan is nonzero, the dispatcher enumerates units. Waiting for outbound mailbox availability is bounded; timeout aborts discovery, and the dispatcher publishes a UNITS boot fatal and exits on the negative enumeration result. (code: software/kohakuaccel/firmware/unit/enumerate.c:9-14, :57-59; software/kohakuaccel/firmware/apps/dispatcher/main.c:44-51; evidence: af7c1bb:software/firmware/kohakuaccel/unit/enumerate.c:7-18, :37-61 spins without an outbound timeout.)
- **L0.BOOT.025** `unproven` Enumeration stops when its output capacity is reached or the inclusive scan grid is exhausted. An outbound mailbox timeout aborts discovery with a negative result; an unanswered capability probe instead skips that coordinate. (code: software/kohakuaccel/firmware/unit/enumerate.c:9-14, :21-38, :51-72; evidence: af7c1bb:software/firmware/kohakuaccel/unit/enumerate.c:7-18, :37-61 spins without an outbound timeout.)
- **L0.BOOT.017** `unproven` With `nunits` nonzero the firmware serves the host's table as given and scans nothing; with `nunits` 0 and `scan` 0 it serves no unit. (code: software/kohakuaccel/firmware/apps/dispatcher/main.c:44; doc: docs/spec/node-queue.md:64, :70-72)
- **L0.BOOT.018** `unproven` The unit table, given or found, is what the firmware computes the machine signature over ([package.md](package.md) L0.PKG.031) and what it publishes in the queue region before it reports ready ([node-queue.md](node-queue.md) L0.NQ.012). (code: software/kohakuaccel/firmware/package/interp.c:158-180; software/kohakuaccel/firmware/queue/service.c:303-307; doc: docs/spec/node-queue.md:70,75-76)

## Firmware memory

- **L0.BOOT.019** `silicon` The firmware's code is linked into the sysnode's instruction memory (`node.imem_bytes` [32768] at 0) and its data and stacks (the queue task's 4 KB among them) into its scratchpad (`node.spad_bytes` [32768] at `node.spad_base`, the boot block first). (code: software/kohakuaccel/firmware/arch/rv64/node.ld:6-56; software/kohakuaccel/firmware/apps/dispatcher/main.c:24-25; software/kohakutpu/firmware/build.py:125-131; evidence: the dispatcher image ran on every card boot)
- **L0.BOOT.020** `unproven` The dispatcher reads and writes its scratchpad, package and queue memory, package-named memory and assigned debug region. It also accesses control registers and mailbox/interlink/mover registers; package-provided addresses are not a memory-protection boundary. (code: software/kohakuaccel/firmware/package/interp.c:101-110, :1213-1282, :1445-1481; software/kohakuaccel/firmware/queue/service.c:113-138; software/kohakuaccel/firmware/package/debug.c:20-36; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
- **L0.BOOT.021** `unproven` Boot region validation rejects zero-sized or wrapping used extents, duplicate uses and overlap. Fatal queue fallback performs this validation and checks boot identity before locating the queue region; it writes only when the region matches the boot queue address, is queue-line aligned and covers the firmware state line. (code: software/kohakuaccel/firmware/queue/service.c:25-45; software/kohakuaccel/firmware/boot/args.c:30-45; evidence: implementation inspection only; no card or named RTL witness established for this complete contract.)
- **L0.BOOT.022** `unproven` Dispatcher images built with the queue service exclude the firmware heap allocator and production queue allocation opcodes 3..5 refuse. These dispatcher-specific restrictions do not establish a card-wide absence of memory management. (code: software/kohakutpu/firmware/build.py:190-208; software/kohakuaccel/firmware/queue/service.c:372-377)
