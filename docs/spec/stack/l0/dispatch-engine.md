# L0 dispatch engine

The hardware queue beside a sysnode's processor that issues control-register
writes at one a cycle and holds each `WAIT` on a completion counter it keeps
itself; how the firmware drives it; and how `engine.lower` turns a bound
package into the entries it runs. The RTL is
`src/kohakuaccel/sysnode/dispatch/dispatch_engine.v` inside
`src/kohakuaccel/pe/rv64-sys/rv64_syscore.v`; the firmware side is
`software/kohakuaccel/firmware/package/interp.c` (engine mode) with registers in
`software/kohakuaccel/firmware/include/ka/dispatch/de.h`; the writer side is
`software/kohakuaccel/compiler/crates/ka-package/src/engine.rs`.

**What the card ran.** Every 2026-10-21 v9t6 package was lowered by
`engine.lower` into `ENGINE` steps and ran through the engine: a sysnode without
one, or with boot flag `NOENGINE`, fails an `ENGINE` step with `BAD_STEP`, and
the runs completed. Those entries were mailbox writes for fetch requests (every
unit had a fetch port), mover writes and `WAIT`s on unit counters and the mover
source. The RTL testbench `tests/sysnode/dispatch_engine_tb.v`
(`vlt.py dispatch_engine`: randomised entry streams against a reference model,
with negative builds `NEG_GO`, `NEG_MV`, `NEG_ROOM`, `NEG_WAIT` that must fail)
covers the interlocks, claims, counters, overflow and clear.

## The engine

- **L0.DE.001** `silicon` `STAT` (control offset `0x300`, read) carries `0xDE01` in `[63:48]` on a sysnode with an engine. In production images, the firmware runs a package through the engine when the magic is present, boot flag `NOENGINE` is clear, the package names at most `fw.engine_units` [16] units and every unit's class uses the generic classifier. (code: software/kohakuaccel/firmware/package/interp.c:1026-1037; src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:240-242; doc: docs/spec/dispatch-engine.md:80-81; docs/spec/package-format.md:308-314; evidence: every card package ran in engine mode; LOG:90 value `de01064302350040` ([debug/firmware.md](../debug/firmware.md) `LOG`, the v9t6 card log))
- **L0.DE.035** `unproven` `STAT` reads 0 on a sysnode without an engine; a package that fails any of those conditions runs on the firmware path. (code: src/kohakuaccel/pe/rv64-sys/rv64_syscore.v:835-840; software/kohakuaccel/firmware/package/interp.c:1051-1052; evidence: the v9t6 sysnode has an engine and every card package met the conditions)
- **L0.DE.002** `silicon` An entry is a 6-bit code and a 64-bit value: codes 0-31 write target register `code` with the value; code 32 is a `WAIT`. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:170-185; doc: docs/spec/dispatch-engine.md:25-32; evidence: every card package)
- **L0.DE.003** `silicon` A store of value `v` at control offset `0x200 + 8c` (`c < 32`) queues a write entry of code `c`; a store at `0x300` queues a `WAIT`. (code: src/kohakuaccel/pe/rv64-sys/rv64_syscore.v:658-660; doc: docs/spec/dispatch-engine.md:72-73; evidence: every card package)
- **L0.DE.004** `silicon` On the RV64 sysnode the write targets are the processor's control registers: codes 0-7 the dispatch mailbox at `0x40 + 8c` (0 `DST`, 1-4 `ARG0`-`ARG3`, 5 `GO`), codes 8-23 the mover at `0x100 + 8(c - 8)`. (code: src/kohakuaccel/pe/rv64-sys/rv64_syscore.v:646-648; doc: docs/spec/dispatch-engine.md:34-38; evidence: the card's fetch requests and moves)
- **L0.DE.005** `unproven` Codes 24-31 write the interlink window at `0xC0 + 8(c - 24)`; a `RING` is code 26 (`0xD0`). (code: src/kohakuaccel/pe/rv64-sys/rv64_syscore.v:646-648; software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:30, :45-46)
- **L0.DE.006** `silicon` A `WAIT`'s value is `src [60:56] | want [node.engine.counter_bits - 1 : 0]` (`node.engine.counter_bits` [12]); the queue holds until `(count(src) - want) mod 2^ctr_bits` is below `2^(ctr_bits - 1)`. A source below `fw.engine_units` [16] is that unit counter; source 16 is the mover's done count since the last clear. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:165-168; doc: docs/spec/dispatch-engine.md:40-44; evidence: every card package's `AWAIT`, `BARRIER` and move waits; tests/sysnode/dispatch_engine_tb.v checks each `WAIT` against the model's counter)
- **L0.DE.007** `unproven` With F-004, lowering replaces each requested WAIT target by the larger of that target and `sent - (2^(node.engine.counter_bits - 1) - 1)` [sent − 2047], using the source unit’s sent count or mover GO count. Only positive targets are emitted. Fetch runs bound outstanding words by the smaller of unit credit and `unit.inst_depth` [512]; mailbox dispatch uses unit credit without the instruction-depth clamp. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:138-152, :198-215, :242-256; evidence: af7c1bb:software/compiler/kohakuaccel/compiler/package/engine.py:69-71 emits positive requested targets without the lower bound.)
- **L0.DE.008** `RTL` At most one entry leaves the head per cycle, in queue order. A write is held while: the processor writes a shared control window that cycle; it is a mailbox `GO` (code 5) and a flit is still offered or the previous `GO` is under `GO_GAP` [3] cycles old; it is a mover code (8-23) and the mover's configuration queue has no room; it is an interlink code (24-31) and a move the engine started is running or owed. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:170-185, :199-203; evidence: tests/sysnode/dispatch_engine_tb.v:118-142,163-174 checks ordered writes, controller hold, mover-room and interlink-move interlocks and absence of overlapping mailbox offers; NEG_GO, NEG_ROOM and NEG_MV perturb the associated inputs)
- **L0.DE.009** `unproven` An accepted CU_SIGNAL from a mapped source, code 0x00 or 0x01, while enabled and not clearing, is claimed and increments the mapped counter. The processor mailbox excludes claimed signals from its completion queue; other accepted CU_SIGNAL messages are delivered to that queue. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:134-151; src/kohakuaccel/pe/rv64-sys/rv64_noc_mbox.v:191-203; tests/sysnode/dispatch_engine_tb.v:71-81,146-157)
- **L0.DE.010** `silicon` `MAP` (control offset `0x310`, write): `[31]` valid, `[19:16]` counter, `[11:8]` y, `[3:0]` x maps a source coordinate to a counter; the map has `2^(2 die.noc.pos_bits)` [256] entries. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:155-158; doc: docs/spec/dispatch-engine.md:77; evidence: every card package's `WAIT`s were met through the counters these maps feed)
- **L0.DE.011** `silicon` `CTL` (control offset `0x308`, write): `[0]` enable, `[1]` clear (queue emptied, counters zeroed over `fw.engine_units` cycles, mover count rebased). (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:88-94, :214-230; doc: docs/spec/dispatch-engine.md:75; evidence: written 3 then 2 around every card package)
- **L0.DE.012** `silicon` Reading `0x380 + 8k` gives counter `k`. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:236-245; doc: docs/spec/dispatch-engine.md:76-78; evidence: the firmware read both counters after the card failure: LOG:86-88 `inflight 3913` and `3916` are `(0 - counter) mod 4096` for `sent 0`, and `outstanding 7829` their sum; tests/sysnode/dispatch_engine_tb.v:343-351 checks every counter against its model)
- **L0.DE.036** `RTL` Reading `MOVES` (the engine's read 1, control offset `0x308`) gives `[43:32]` moves started since the clear. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:243; doc: docs/spec/dispatch-engine.md:76-78; evidence: tests/sysnode/dispatch_engine_tb.v:352-356)
- **L0.DE.037** `unproven` MOVES bits `[node.engine.counter_bits - 1:0]` [11:0] report mover completions since clear. Firmware reads them to validate final chain settlement. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:163, :243; software/kohakuaccel/firmware/package/interp.c:968-981; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
- **L0.DE.013** `silicon` `STAT` fields: `[47:40]` log2 depth, `[39:36]` log2 counters, `[35]` overflow, `[34]` clearing, `[33]` head blocked, `[32]` enabled, `[31:16]` entries issued, `[15:0]` entries queued. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:236-245; doc: docs/spec/dispatch-engine.md:74; evidence: the firmware read the magic, depth, issued, queued and overflow fields for every card package (interp.c:632-653, :657-674, :925-943, :1029-1068); LOG:90 value `de01064302350040` decodes as depth 64, 16 counters, no overflow, not clearing, head blocked, enabled, 0x235 issued, 64 queued (the reported occupancy at the FIFO-depth budget); tests/sysnode/dispatch_engine_tb.v checks magic, queued and overflow)
- **L0.DE.014** `RTL` Enqueueing when the FIFO itself holds `node.engine.depth` [64] entries drops the write and sets overflow until clear. A separate head register permits total reported occupancy of depth plus one [65]. (code: src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:70-80, :88-108, :211-228, :236-242; evidence: tests/sysnode/dispatch_engine_tb.v:238-257 exercises overflow at FIFO capacity.)
- **L0.DE.015** `unproven` The FIFO has `node.engine.depth` [64] entries plus one head register. Firmware derives its enqueue budget solely from the STAT log2 FIFO-depth field and limits tracked occupancy to that depth. (code: src/kohakuaccel/pe/rv64-sys/rv64_syscore.v:39, :821-828; src/kohakuaccel/sysnode/dispatch/dispatch_engine.v:70-80, :236-242; software/kohakuaccel/firmware/package/interp.c:657-698, :1066-1068; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)

## The firmware in engine mode

- **L0.DE.016** `unproven` Before the first step of a package that does not join a held chain (L0.NQ.057), the firmware unmaps the coordinates it mapped for the previous package, maps unit `i`'s coordinate to counter `i`, writes `CTL` 3 (clear and enable), and takes the queue's room as its depth. A package that joins a held chain keeps the counters running and is L0.NQ.057. (code: software/kohakuaccel/firmware/package/interp.c:1038-1072; doc: docs/spec/dispatch-engine.md:86-90; evidence: current implementation inspected; no extant named RTL witness established for this statement.)
- **L0.DE.017** `unproven` After the last step of a package that is not chained to the next (L0.NQ.057), the firmware queues the end barrier (a `WAIT` per unit for the larger of its words sent and its expected count, then a `WAIT` on the mover source for the package's GOs), waits until `STAT`'s queued count is 0, and writes `CTL` 2 (clear, disabled). A chained package queues the end barrier and leaves the engine running without the drain or `CTL` 2 (L0.NQ.057). (code: software/kohakuaccel/firmware/package/interp.c:913-953, :1094-1101, :1880-1896; doc: docs/spec/dispatch-engine.md:90; evidence: current implementation inspected; no extant named RTL witness established for this statement.)
- **L0.DE.041** `unproven` With a peek callback, a nonlocal, nonchained package with no failure yet recorded and still in engine mode invokes it after queuing the end barrier and before draining. The callback may find no queued next entry. (code: software/kohakuaccel/firmware/package/interp.c:1880-1896; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
- **L0.DE.018** `silicon` The firmware queues an entry only while it holds room; with none left it reads `STAT` and takes `depth - queued` as its new room. (code: software/kohakuaccel/firmware/package/interp.c:657-698; doc: docs/spec/dispatch-engine.md:80-82; evidence: every card package longer than 64 entries)
- **L0.DE.019** `unproven` While waiting for room or drain, firmware reports TIMEOUT detail 11 (ENGINE), value the raw STAT, if the issued count has not changed for one timeout. Issued-count progress restarts the timeout budget. (code: software/kohakuaccel/firmware/package/interp.c:644-651)
- **L0.DE.038** `unproven` While it waits for room or for the drain, the firmware also pops whatever reaches the processor's completion queue (a fault fails the package `UNIT_FAULT`), reads `MVSTAT` and fails `MOVER_FAULT` on a mover fault, and fails `BAD_STEP` (detail `0xDE`, value `STAT`) on overflow. (code: software/kohakuaccel/firmware/package/interp.c:632-643; doc: docs/spec/dispatch-engine.md:90-96; evidence: no card log or test shows a unit fault, a mover fault or an overflow)
- **L0.DE.020** `unproven` Dispatch-engine end quarantines an engine failure, including a failure discovered while settling held work. Quarantine disables dispatch, reports the saved engine snapshot, publishes fatal state and exits. Successful settlement reaches de_stop; failure does not reconstruct outstanding work from modular counters or proceed through ordinary quiesce. (code: software/kohakuaccel/firmware/package/interp.c:1077-1102; evidence: af7c1bb:software/firmware/kohakuaccel/package/interp.c:1565-1581 prints failure counters and quiesces before returning a result.)
- **L0.DE.021** `unproven` Mailbox DST and ARG0–ARG3 writes are omitted when the shadow already holds the value. Host lowering clears its shadow after each nonempty ENGINE step and invalidates ARG3 before fetch. Firmware resets its shadow on starting or joining engine mode and after default-fallback execution; explicit ALU, JUMP and PATCH cases return without that reset. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:155-195, :231-232; software/kohakuaccel/firmware/package/interp.c:705-714, :1043-1046, :1066-1069, :1701-1715; evidence: af7c1bb:software/compiler/kohakuaccel/compiler/package/engine.py:73-92, :111-112 implements host deduplication; no card witness established for the complete firmware-case claim.)

## `ENGINE` steps

- **L0.DE.022** `unproven` Eligible lowering preserves units, buffers, signature, ack_reserve and checksum flag, converts supported steps to ENGINE entries and preserves fallback steps. Expanded REPEAT payloads are appended as encountered; packed ENGINE payloads are appended whenever pending entries are cut. Both follow original payloads, but can interleave. Traversal stops at the first END without copying it or later steps, then emits a final barrier and cuts pending entries. L0.DE.033 describes unchanged-return cases. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:164-195, :263-293, :351-354, :397-495)
- **L0.DE.023** `silicon` An `ENGINE` step's payloads hold three entries each: word 0 holds the three code bytes in bytes 0-2 (`0xFF` for none), words 1-3 the three values; the step's count is the number of entries. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:164-191; software/kohakuaccel/firmware/package/interp.c:883-906; doc: docs/spec/package-format.md:317-319; evidence: every card package)
- **L0.DE.024** `unproven` Firmware reads ENGINE entries in order, adds the payload base shifted left24 for REL, clears REL, rejects codes above WAIT, rebases WAIT for chains and applies interlink room checks to RING before enqueueing. (code: software/kohakuaccel/firmware/package/interp.c:738-753, :873-908; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
- **L0.DE.025** `unproven` A code above 32 once `REL` is removed fails the package with `BAD_STEP`, detail 11, value the code word. (code: software/kohakuaccel/firmware/package/interp.c:885-894; doc: docs/spec/package-format.md:321)
- **L0.DE.026** `unproven` Firmware rejects ENGINE if first exceeds the payload count or count / 3 + (count % 3 != 0) exceeds the remaining payloads. This overflow-safe ceiling division returns BAD_LAYOUT with detail first and value the payload count on refusal. (code: software/kohakuaccel/firmware/package/interp.c:878-879; evidence: implementation inspection only; no card or named RTL witness established for this complete contract.)
- **L0.DE.027** `unproven` Host lowering determines its credit waits and register entries. Firmware additionally applies REL adjustment, chain WAIT rebasing and RING room handling. Host and firmware lowering are not entry-identical: firmware REPEAT uses mailbox words even when a fetch port exists; host lowering can fetch expanded payloads. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:207-293; software/kohakuaccel/firmware/package/interp.c:771-832, :873-908; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)

## What the lowering writes

- **L0.DE.028** `silicon` A `DISPATCH` to a unit with a fetch port becomes fetch runs (L0.STEP.044, L0.STEP.045): per run a `WAIT` on the unit for `sent + n - room` when positive, `DST`, `ARG0`, `ARG1`, `ARG2` (deduplicated), `ARG3` with `REL` and value `payload offset << 24 | 0x60 << 8 | n`, then `GO` 1. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:207-237, :242-246; evidence: every card dispatch)
- **L0.DE.029** `unproven` For a DISPATCH without a fetch port, host lowering requests sent + 1 - credit per word, writes DST = y << 8 | x and deduplicated ARG0-ARG3, then GO 1. The WAIT helper applies the F-004 lower bound and emits only positive resulting targets. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:138-161, :248-256)
- **L0.DE.030** `unproven` AWAIT adds its count to the expected frontier and requests that target. BARRIER requests max(sent, expected) for each unit and the mover GO count. MOVER writes registers, counts GOs and requests the mover GO frontier unless POSTED. MWAIT requests its count as an absolute mover frontier. Targets pass through the F-004 lower bound and only positive results emit. Any flagged AWAIT returns the entire package unchanged. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:138-152, :296-343, :351-354, :441-489)
- **L0.DE.031** `unproven` With F-003, a RING remains a firmware step: lowering flushes pending entries, and firmware fallback drains before executing it and invalidates the mailbox shadow. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:419-427, :480-484; software/kohakuaccel/firmware/package/interp.c:1708-1715; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
- **L0.DE.032** `unproven` `FETCH` becomes fetch runs at its absolute address (no `REL`); `REPEAT` becomes its repetitions written out as payloads and sent as a `DISPATCH`. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:263-293, :479)
- **L0.DE.033** `unproven` Lowering returns the package unchanged if any JUMP or PATCH exists, or any AWAIT has nonzero flags. These checks precede relocation and unit-count refusals. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:351-354, :397-417; evidence: af7c1bb:software/compiler/kohakuaccel/compiler/package/engine.py:195-200 has JUMP/PATCH early return but not flagged AWAIT.)
- **L0.DE.039** `unproven` After L0.DE.033 unchanged returns, lowering refuses remaining relocations or more than `fw.engine_units` [16] units. It refuses ENGINE only when encountered before END during traversal. (code: software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:351-354, :397-417, :431-481; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
- **L0.DE.040** `unproven` Replay reconstructs each REPEAT word from its template and repetition-scaled increments, refusing field wrap. Both direct word dispatch and appended-payload FETCH compare the emitted words against those reconstructed values; FETCH also checks relative addressing, alignment and appended-payload extent. (code: software/kohakuaccel/compiler/crates/ka-package/src/replay.rs:182-201, :278-284, :346-362; evidence: implementation inspection only; no card or named RTL witness established for this complete contract.)
- **L0.DE.034** `unproven` In engine mode firmware converts DISPATCH, REPEAT, AWAIT, BARRIER, MOVER, MWAIT and FETCH using its counters. DISPATCH with a fetch port uses absolute payload addresses; REPEAT sends mailbox words regardless of fetch availability. ALU/JUMP execute directly; PATCH drains first only on a held-chain join. Default fallback drains, executes on firmware and invalidates the shadow. (code: software/kohakuaccel/firmware/package/interp.c:755-832, :913-921, :1659-1716; software/kohakuaccel/compiler/crates/ka-package/src/engine.rs:242-293; evidence: Code inspection; no qualifying card or named RTL witness established for this complete statement.)
