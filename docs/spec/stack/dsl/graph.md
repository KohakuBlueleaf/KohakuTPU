# DSL: the `kt` tracer and the graph it produces

`kohakutpu.language.dsl` (`kt`) traces a Python function once per
specialisation into a tree of L2 statements and prints it as an L2 module.
The new stack keeps the tracer in Python and hands the Rust backend the
traced graph (owner ruling: the DSL is a Python tracer producing a graph;
the Rust backend analyses it and produces L2 and the steps after; the
tensor-level API and the tinygrad device hand Rust their programs the same
way); the graph
contract below (DSL.GRAPH) is what the current tracer's output implies.
Clause format, ids and evidence tags: `../README.md`.

Evidence on this page:

- `silicon`: the construct is unchanged since the 2026-10-21 card run (the
  tree at `af7c1bb`; `git diff af7c1bb` touches only `xrot`, `unpack lane=`
  and the statistic pack / store in `dsl/ops.py`) and the generators of the
  455 card kernels at `af7c1bb` (`software/application/kohakutpu/application/kernels/{vector,convert,matmul,transpose}.py`,
  every one built by `Kernel.build` with a `TensorSpec` for every port)
  used it, their L1 showing the
  instruction it lowers to. A refusal or error path is never `silicon`.
- `RTL`: `software/application/tests/ktpugrad/test_tinygrad.py` on the
  Verilated card, current tree, 76 of 80 cases passing
  (the 4 misses are matmul tolerance, MXFP7 precision), whose generated kernels use the construct; its
  `test_a_dsl_kernel_inside_a_tinygrad_program` runs the example
  `examples/dsl/vector/softmax.py` (a `@kt.kernel` with named extents and
  `rows=kt.auto(16, 8, 4)`) through `ktpugrad.bridge` on a [16, 128] input.
  Or `software/application/tests/dsl/test_examples_card.py`, the examples
  run on `build/v9f/vlt_card_v9_{1,2}n_v2` as recorded in
  `docs/projects/kohakutpu/dsl.md:116-134` (conflict 7).
- `unproven`: neither. Every trace-time refusal is a host check no card run
  witnesses; each is listed so a test can name it.

Machine facts are machine-schema parameters with the v9t6 value in brackets.
The tracer reads `vc.lanes` and `vc.chunk` from its supplied machine (RUL.018),
and its target from `machine.target` (RUL.010):
`mg.count` [2], `vc.count` [2], `card.nodes` [4; the card run used 1],
`vc.lanes` [16, one 32-byte word of f16, the lanes of a chunk],
`die.word_bytes` [32], `vc.vlmax` [128]
(`boards/multimesh_v9t6.json:5`, `:74-95`). A GT4 register holds the
`vc.vlmax` values as a band of 4 rows by 32 columns (two `vc.lanes` chunks a
row).

## 5. Control

Generated vector stages use the active node's vector-core count, supplied by
the machine schema, without a generator default. For n trips and p active
instances, core c covers `[ceil(c*n/p), ceil((c+1)*n/p))`; every trip is
covered exactly once. p is the smaller of n and `node.vc` (an empty stage
has one zero-trip instance). This applies to any core count; tier-0 tests
cover vc = 1..4 (API.ROW.007, RUL.016).

- **DSL.CTRL.001** `silicon` `for u in kt.par(n, on=UNIT)` records `par u in 0..n on KIND[u]` and runs the body once with `u` a symbol. (code: ops.py:31-75; doc: dsl.md:43-46; evidence: silicon images `..._n0_vc0_0`, `..._n0_vc1_1` (`par` on vc), the mm kernels' `send mg[..]` (`par` on mg), from `kt.par(n, on=kt.vc)` / `kt.par(ncl, on=kt.mg)` in kernels/*.py at af7c1bb)
- **DSL.CTRL.002** `silicon` `on=` is `kt.mg` or `kt.vc` with no index and no node. (code: ops.py:53-56; evidence: as DSL.CTRL.001)
- **DSL.CTRL.003** `silicon` Generated par variables are `u1, u2..` (mg), `c1..` (vc); a name taken by a port, a scratch buffer or an earlier name is skipped. (code: ops.py:165-166; trace.py:77-92; evidence: every generated `par` takes a generated name, kernels/*.py at af7c1bb)

(code: ops.py:515-552; inventory L-051; evidence: silicon `copy w(src+2432, (3, 10368), (14, 576), (14, 32), (5, -576), (5, -32)) -> ...`, the walk kernels (74))
- **DSL.MOV.003** `silicon` `kt.quant(dst, src)` records `quant DST <- SRC`: row-major f16 into an mx7a/mx7b packing by the mover's quantiser. (code: ops.py:555-557; evidence: silicon fn `quant` 172 in 25 kernels)
- **DSL.MOV.004** `silicon` `kt.gt4(dst, src, walk=None, at=None, dwalk=None, dat=None)` records `gt4 DST <- SRC ...`: row-major f16 into 4 x 4 sub-tiles; with walks (whole buffers) each group of four source words goes to four consecutive words, word i the 8-byte granule i of each. (code: ops.py:560-577; inventory L-031; evidence: silicon fn `gt4` 442 in 38 kernels, the transpose generator's walked `kt.gt4` (kernels/transpose.py at af7c1bb))
- **DSL.MOV.005** `silicon` `kt.fill_value(dst, value, ew=None, walk=None, at=None)` records `fill DST value=V [ew=E] [walk=..] [at=..]`: the 32-bit immediate (or its low `ew` bits repeated) over dst. (code: ops.py:580-592; inventory L-030; evidence: silicon fn `fill .. value` 503, `ew=16` 194 in 30 kernels)
- **DSL.MOV.009** `unproven` `kt.copy(dst, src, perm=(..))` prints `perm=(..)` (word axes of the source reordered). (code: ops.py:531-538; evidence: no generated kernel passes `perm`)
- **DSL.MOV.010** `unproven` A walk copy, walk gt4 or walk fill over a view rather than a whole buffer is refused; a gt4 with one walk but not the other is refused. (code: ops.py:539-542, :565-568, :583-584; evidence: refusals, no card or RTL run)
- **DSL.MOV.006** `unproven` `kt.gen(dst, seed)` records `gen DST seed=S`: address-keyed pseudo-random words. (code: ops.py:595-597)
- **DSL.MOV.007** `RTL` `kt.gather(dst, src, index, fp=False)` records `gather DST <- SRC [fp] index=IDX` (row r of dst := row index[r] of src); `kt.scatter` likewise (row index[r] of dst := row r of src). `fp=True` reads an fp32 index list. (code: ops.py:600-607; evidence: the lane relayout, kernels/lanes.py:174-181, test_tinygrad.py gather-path cases)
- **DSL.MOV.008** `silicon` Mover keyword arguments that are None are omitted, others print `k=v`. (code: ops.py:501-512; evidence: the walk / fill generators' `walk=`, `at=`, `dwalk=`, `dat=`, `value=`, `ew=` (tally `fill .. value=0 ew=16`); `kt.copy`'s unset `perm` omitted)
- **DSL.MOV.011** `RTL` Mover keyword arguments that are True print as bare flags after the operands. (code: ops.py:501-512; evidence: the lane relayout's `kt.gather(.., fp=True)` (kernels/lanes.py:174-181): test_tinygrad.py `narrow_transpose`)
- **DSL.MOV.012** `unproven` Mover keyword arguments that are False are omitted. (code: ops.py:506-511; evidence: no generator passes a False keyword)

## 11. L2 text

- **DSL.TEXT.001** `silicon` The module prints `target {machine.target}`, a blank line, `fn NAME.l2(p: SPEC, ...)` with the ports in port order, then the body indented four spaces a level: the scratch buffers first, then the recorded statements; the text ends with a newline. (code: trace.py:16, :117-124; inventory L-004; evidence: every card kernel)
- **DSL.TEXT.002** `silicon` A statement prints `[TARGET = ]OP ARGS`: operands joined by `, `, except `par`, `for`, `when`, `if` and any statement with `->` or `<-`, whose operands join by spaces; keyword arguments follow, space-separated, as `k=v`. (code: trace.py:20-43; evidence: host path of every card kernel's trace, read back by the L2 reader (`docs/spec/stack/l1/program.md` L1.MOD.004); trace.py unchanged since af7c1bb)
- **DSL.TEXT.003** `silicon` A value statement carries its type as an annotation `: TYPE`; in each block annotations align two columns past the longest annotated statement head, at most column 48; a head at or past that column is followed by two spaces then `: TYPE`. (code: trace.py:17, :127-142; evidence: host path of every card kernel's trace; trace.py unchanged since af7c1bb)
- **DSL.TEXT.004** `silicon` A number operand prints as Python's `repr` of the float (`-1.4426950408889634`, `5.0`). (code: ops.py:407-409; evidence: number operands of the card kernels reach the L1 as `seti s0 = 0.95` (138 / 70))
- **DSL.TEXT.005** `silicon` Each statement records the author's `file:line` (the innermost frame outside the DSL package and `contextlib`, so a `when` / `if sticky` names the `with` line) for the L2 -> DSL source map. (code: trace.py:29-30, :99; errors.py `FOREIGN`, `_inside`, `at_caller`; test: language/tests/dsl/test_graph.py `test_when_and_sticky_point_at_the_authors_line` and its witness `test_without_the_contextlib_skip_the_line_is_contextlibs`; evidence: host path of every card kernel's trace (`t.emit`))
- **DSL.TEXT.006** `unproven` Every `DSLError` message ends `, at FILE:LINE`. (code: errors.py:18-41; ops.py call sites; evidence: error path, no card or RTL run checks a message)

## 12. Several nodes

- **DSL.NODE.001** `unproven` Outside a par over nodes, a `kt.par(n, on=kt.mg | kt.vc)` from 0 with `n` larger than one node's units (`mg.count` / `vc.count`) on a machine of several nodes spans the nodes: it records `par nN in 0..USED on node[nN]` around `par V in 0..SHARE on KIND[V]`, the body's variable `nN * SHARE + V`. (code: ops.py:60-66, :78-105; doc: dsl.md:97-104; inventory L-010; evidence: dsl.md:122-127 records 2-node runs on build/v9f; the card ran one node)
- **DSL.NODE.002** `unproven` With `at=None` the share is one node's units: `n` must be a multiple of them and need at most `card.nodes` nodes; with `at=kt.ANY` the share is `n / nodes` (n a multiple of nodes) and the unit prints `KIND[any]`; any other `at` is refused; an uneven split is refused ("do not split evenly"). (code: ops.py:82-97)
- **DSL.NODE.003** `unproven` Inside a par over nodes, a wide par does not span nodes again. (code: ops.py:64; trace.py:53)
- **DSL.NODE.004** `unproven` `kt.node[N].mg[J]` names another node's cluster; `kt.drain(acc, kt.node[N].mg[J], add=True)` records `drain ACC -> mg[J] add node=N`: the tile added into that cluster's accumulator across the interlink. A cross-node drain without `add`, or to a core, is refused; `.mg` / `.vc` of anything but `kt.node[N]` is refused. (code: values.py:31-49; ops.py:270-278; doc: dsl.md:105-109; inventory L-019; evidence: example `splitk`, dsl.md:127)

## 13. The graph contract

The traced graph the Rust backend takes, as the current tracer defines it.

- **DSL.GRAPH.001** `silicon` A trace is one module: a kernel name, a target (`ktpu.v9`), an ordered list of ports `(name, TensorSpec, role in|out)`, an ordered map of scratch buffers `(name, TensorSpec)`, the constants it was traced with, the `Machine`, and a root block. (code: kernel.py:75-89, :277-296; trace.py:56-70; evidence: every card kernel's trace, `target ktpu.v9` 455 / 455)
- **DSL.GRAPH.002** `silicon` A block is an ordered list of statements; a statement is `(op, args, target, annotation, body, where)`: `body` is a block for `par` and `for` and None for every other op the card kernels hold. The tree is the only control structure: no edge leaves a block. (code: trace.py:20-31, :103-114; evidence: the af7c1bb generators' traces)
- **DSL.GRAPH.003** `silicon` Node kinds by op: control `par` (variable, lo, hi, unit kind, unit index expr), `for` (variable, lo, hi); scratch `buffer`; cluster `fill zero gemm drain`; vector `load unpack pack store`, the math ops of DSL.VEC.006, `rmax rsum`; mover `copy quant gt4 fill`. (code: ops.py:36-607; evidence: as DSL.SCOPE.001)
- **DSL.GRAPH.004** `silicon` A value node defines one name with a type `(dtype, shape, space, mode)`: dtype f16 / f32 / mx7a / mx7b, shape a tuple of ints, space A / B / acc / l1 / reg, mode gt4 or none; math, unpack and reductions are f32 @reg, a cluster tile f32 @acc. (code: values.py:195-226; ops.py:195-208; evidence: as DSL.VAL.001)
- **DSL.GRAPH.005** `silicon` Names are not single-assignment: a `gemm` into `acc` defines an existing name again (the later definition reaching the uses after it in program order, and a loop carrying it). (code: ops.py:252-259; evidence: `acc=1` 4157 chained sweeps in the mm kernels' `kt.range` loop)
- **DSL.GRAPH.006** `silicon` An operand is a value name, a value name broadcast across the row (`NAME[:, *]`, a statistic of a row op), a float literal, or a buffer `View` (buffer name + axes run / all). (code: values.py:95-131; ops.py:407-414; evidence: `vmul` bcast 1648, `seti s0 = 0.95`, the generators' views)
- **DSL.GRAPH.007** `silicon` Index expressions inside views and par bounds are affine forms over the enclosing `par` / `for` variables. Every variable is bound by an enclosing `par` or `for`. (code: expr.py:30-265; ops.py:68-72, :121; evidence: as DSL.IDX.001)
- **DSL.GRAPH.008** `silicon` Unit references are `(kind, index expr, None)` with kind mg or vc. (code: values.py:27-60; evidence: the `par .. on mg` / `on vc` of the card kernels)
- **DSL.GRAPH.009** `silicon` Mover attributes: walks are tuples of `(count, signed byte stride)` outermost first; `at` / `dat` byte offsets; `value`, `ew` ints. (code: ops.py:500-607; evidence: tally `copy w(..)` with negative strides, `fill .. value=0 ew=16`)
- **DSL.GRAPH.010** `silicon` Each statement carries its source location; a value carries its defining statement and block, and an @l1 value its unpacked register value once made (one unpack per @l1 value). (code: values.py:200-216; trace.py:29-30; evidence: host path of every card kernel's trace)
- **DSL.GRAPH.011** `unproven` The tracer checks scope legality (DSL.SCOPE.001), view bounds for constant starts (DSL.VIEW.003), type rules (DSL.VEC, DSL.CL), and nothing else: L1 capacity, descriptor count, bank depth and timing are the backend's (the L2 compiler refuses with the L2 line, `TextError`). (code: ops.py; software/compiler/kohakutpu/stack/kernel.py; evidence: a division of refusals; no card or RTL run takes a refusal)
- **DSL.GRAPH.012** `unproven` The other graph forms: a `par` unit index `any`; a `for` `pipe`; `if sticky` blocks; a `Cond` op `< <= > >=`; cluster `recv`; vector `send` and `recv`; mover `gen`; `Value.assign` redefining a name; a buffer `View` axis `idx` or `new`; `/`, `%`, `*` index atoms; a unit reference of kind node or with a node (only a `drain .. add` target); mover attributes `perm`, `seed`, `share`, `side`, `add`, `node`, `lane`. (code: ops.py:36-607; values.py:27-131, :342-356; expr.py:30-265; evidence: none is in a card kernel or a passing card test's kernels (DSL.CTRL.005, .007, .011, DSL.CL.005-.008, DSL.VEC.003, .020, DSL.MOV.006, .009, DSL.NODE.*))
- **DSL.GRAPH.013** `RTL` `when` blocks of a `Cond` `(==|!=, a, b)`; mover `gather` / `scatter` with an `index` buffer view and the `fp` flag; a `ValueView` operand. (code: ops.py:128-139, :600-607; values.py:363-402; evidence: DSL.CTRL.006 (splitk, test_examples_card.py), DSL.MOV.007 (the lane relayout's `index[lo : lo + ne]` views, kernels/lanes.py:166-181, test_tinygrad.py `narrow_transpose`), DSL.VAL.005 (attention, test_examples_card.py))

## 14. The graph as JSON

`Traced.graph` (`Kernel.graph(given, **consts)`) holds DSL.GRAPH as plain
JSON (`software/language/kohakutpu/language/dsl/graph.py`); `ktpu-graph`
(`software/rust/crates/ktpu-graph`) reads it and prints the L2 text the
tracer prints for the same trace. Goldens: `software/rust/golden/graph/*.json`
(`graph_dump.py`: the DSL examples on one and two nodes, the
`graph_dump.FORMS` kernels of DSL.GRAPH.012's forms, every frozen
`dsl.trace` / `dsl.graph` vector that traces).

- **DSL.GRAPH.014** `unproven` A graph is `{format: "ktpu.graph", version: 1, name, target, machine: {mg, vc, nodes}, consts, ports: [{name, role, spec}], scratch: [{name, spec}], body}`; a spec is `{dtype, shape, layout: [[key, VALUE]], space}`, VALUE `{int}`, `{str}`, `{bool}` or `{ints}` (`tile`); `consts` is plain JSON, any other object its `repr`. Another format or version, or a malformed graph, is refused. (code: dsl/graph.py `module`, `spec`; ktpu-graph src/graph.rs, lib.rs `parse`; evidence: language/tests/dsl/test_graph.py, ktpu-graph tests/golden.rs, tests/clauses.rs `dsl_graph_001_format_and_version`)
- **DSL.GRAPH.015** `unproven` A statement is an object tagged `kind` with its `where`: `par {var, lo, hi, unit, body}`, `for {var, lo, hi, pipe, body}`, `when {cond, body}`, `sticky {body}`, `value {op, target, type, args, kw}`, `store {dst, src}`, `drain {src, dst, add, node}`, `send {src, dst, side}`, `mover {op, dst, src, flags, kw}`; a statement recorded without its node (a patched recorder) is `unrecorded {op, args}` (its text), which ktpu-graph refuses; the target of a rebound name (`gemm` into `acc`, `Value.assign`) is the name it rebinds. (code: dsl/ops.py `node=` of each `emit`, dsl/graph.py `block`; ktpu-graph src/graph.rs `Node`; evidence: as DSL.GRAPH.014)
- **DSL.GRAPH.016** `unproven` An index is an int or `{const, terms: [[ATOM, COEF]]}` in the `Sym`'s term order, ATOM `{var}`, `{floor | mod | mul: [A, B]}`; a condition `{op, a, b}`; a view `{buffer, axes}`, an axis `"all"`, `"new"`, `{run: [LO, SIZE]}` or `{idx: E}`; a unit `{kind, index}`, index null for `KIND[any]`; a value type `{dtype, shape, space, mode}`. (code: dsl/graph.py; ktpu-graph src/graph.rs; evidence: as DSL.GRAPH.014)
- **DSL.GRAPH.017** `unproven` An operand is `{value}`, `{bcast}` (`NAME[:, *]`), `{float}` (a number, or `"inf"`, `"-inf"`, `"nan"`), `{vview: {value, axes}}`, `{view}` or `{unit}`; a keyword `[KEY, ATTR]`, ATTR `{int}`, `{str}`, `{walk: [[N, S]]}`, `{perm}`, `{view}` (`index=`) or `{index}`, the keywords that print in their order (None omitted). (code: dsl/graph.py `attrs`, dsl/ops.py `_operand_node`, `_mover`; ktpu-graph src/graph.rs; evidence: as DSL.GRAPH.014)
- **DSL.GRAPH.018** `unproven` ktpu-graph refuses a graph whose buffer names repeat, whose operand names a value no earlier statement defines or a buffer no port or scratch is (DSL.GRAPH.006), whose index names an unbound variable (DSL.GRAPH.007), whose statement runs out of its scope (DSL.SCOPE.003), whose block is empty (DSL.CTRL.009), whose par sits in a unit's instance (DSL.CTRL.012), whose variable an enclosing par or for binds already (DSL.CTRL.013); `analyse` also refuses a graph traced for another machine's mg / vc counts or more nodes than the card has (DSL.KERN.011). (code: ktpu-graph src/analyse.rs; evidence: ktpu-graph tests/clauses.rs, one test a clause)
- **DSL.GRAPH.019** `unproven` The stage `to_l2(graph_json, machine)` builds the `ktpu_l2::Program` from the graph's statements and terms (`ktpu_l1::text::{Stmt, Term}`, through `Program::build`): as a tree (target, register file, parameters, scratch, every node's op, target, type, terms and block) it is the program ktpu-l2 reads from the tracer's text. An index term is the tree the tracer's spelling of it reads to (DSL.IDX.006, .009: a sum inside another atom is bracketed). Two printers, two texts: `program.text()` is ktpu-l2's (`ktpu_l1::text::emit_at`, the passes' `syntax.emit` style: `c * 32`, annotation column from the indent), and ktpu-graph's `lower(&graph).text()` is the tracer's DSL.TEXT.001-.004 text byte for byte (`c*32`, absolute column 48), kept as the trace's dump. (code: ktpu-graph src/term.rs, src/analyse.rs `build`, `program`, lib.rs `to_l2`, src/text.rs `lower`; evidence: ktpu-graph tests/golden.rs over every graph golden and every traced e2e golden; tests/clauses.rs `dsl_graph_019_stage_gives_the_l2_program`, `dsl_idx_009_index_terms_read_as_the_tracers_spelling`)
