# ISA: the V2 vector core

What the stack relies on in the V2 vector core (`src/kohakutpu/vector2/`, framed
by `src/kohakutpu/vector/vec_cu.v`): its state, its 32-bit instruction words,
the CU instructions that load and start it, and the ordering rules between its
engines. Clause format, ids and evidence tags: [../README.md](../README.md).
Number formats (E8M15, MXFP7) are defined in
[../numerics/formats.md](../numerics/formats.md); this page states only where a
conversion happens.

Paths are relative to the repository root. `tally` is the instruction
tally of the card run's kernels; "N in K" means N instructions in K of the
455 kernels the v9t6 card ran. RTL testbenches are in `tests/`.

`CARD2` is the v9t6 card batch of 2026-10-22: node 0 over XDMA at the idle
profile, sys 100 MHz, today's tree, every vector's clause and mutants run in
both stacks (Rust 287/287, Python 232/232; Linux host ledgers
`~/ktpu/sweep/cb-rs.done` and `cb-py.done`). It is the silicon evidence of
ISA.VC.006, .013, .024, .026, .055, .057, .062, .074, .076, .080, .081, .082,
.095, .105, .112, .145 and .165, through their `isa.card.*` vectors.

The v9t6 build: `VEC_CORE v21` (`scripts/tcl/v9t3/00_config.tcl:11`, inherited
by v9t4..v9t6), so `RW` 7 and `RF_COPIES` 2 (`scripts/tcl/v8t3/00_config.tcl:119-120`),
`DUALQ` 0 (no `V2_DUALQ` define), `V2_MQ_SKID` 1 (`scripts/tcl/v9t5/00_config.tcl:23`),
every other parameter at its `v2_core.v` default.

## 1. Machine parameters

- **ISA.VC.001** `silicon` A vector core has `vc.lanes` [16] lanes; one math beat processes one chunk of 16 elements. (code: src/kohakutpu/vector2/v2_lanes.v:313-325, :374-385; src/kohakutpu/vector2/v2_core.v:466; evidence:  every math instruction in tally image, e.g. vmul 7225 in 173)
- **ISA.VC.002** `silicon` A vector register is `vc.chunks` [8] chunks of `vc.lanes` elements, `vc.vlmax` [128] elements, each a 24-bit E8M15 value. (code: src/kohakutpu/vector2/v2_core.v:37, :197-198; src/kohakutpu/vector2/v2_lanes.v:93-99, :177-190, :316-323; evidence:  tally image vunpk 8581 in 279, vpack 5868 in 279)
- **ISA.VC.003** `silicon` The v9t6 configuration selects VEC_CORE v21 with RW seven and vc.regs [128]. Zero extension bits name registers zero through 31; higher indices are ISA.VC.004. (code: scripts/tcl/v9t6/00_config.tcl:7; scripts/tcl/v9t5/00_config.tcl:8; scripts/tcl/v9t4/00_config.tcl:6; scripts/tcl/v9t3/00_config.tcl:11; scripts/tcl/v8t3/00_config.tcl:119-120; src/kohakutpu/vector2/v2_core.v:71-75, :197-200, :279-290; evidence:  silicon kernels name v0..v31 only (grep of the 455 sources), target ktpu.v9)
- **ISA.VC.004** `unproven` For RW>5 each register field has RW-5 high bits above instruction bit 31, ordered vc,vb,va,vd. At RW seven these occupy [33:32],[35:34],[37:36],[39:38]. CU IMEM payload [39:32] supplies the extension bits. (code: src/kohakutpu/vector/vec_cu.v:270, :548; src/kohakutpu/vector2/v2_core.v:199-200, :253-261, :279-290; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.005** `silicon` The core has `vc.sregs` [16] scalar registers S0..S15 and `vc.kregs` [4] constant registers K0..K3, 24 bits each. Silicon images read S0, S1, S2, S15 and K0..K2; S3..S14 are ISA.VC.013, K3 ISA.VC.014. (code: src/kohakutpu/vector2/v2_core.v:213-214, :333-340; evidence:  silicon `vmul v20, s0, v4`, `vsel v13, v4, k0, v0` (kernel 0465d012), `vmul v4, v0, s1` (kernel 02488988), `seti s15 = 469`, tally image seti 320 in 185)
- **ISA.VC.006** `silicon` Each predicate register holds vc.lanes*vc.chunks [128] bits, one per lane per chunk. Compare writes and predicated reads are described in ISA.VC.057 and ISA.VC.080-082. (code: src/kohakutpu/vector2/v2_lanes.v:332-337, :351-374, :383-385, :400-408; evidence: documented v9t6 vector execution tally in this page)
- **ISA.VC.007** `silicon` L1 is `vc.l1_words` [512] words of `die.word_bytes` [32] bytes (256 bits), in `vc.l1_banks` [2] banks selected by the word address MSB. (code: src/kohakutpu/vector2/v2_core.v:39, :192-195, :263-275, :835, :840-848; evidence:  silicon L1 offsets up to l1[510] (kernel 0465d012))
- **ISA.VC.008** `silicon` An L1 word holds fp16 element e of 0..15 at bits [16e+15:16e]; lane e of a chunk takes element e. (code: src/kohakutpu/vector2/v2_core.v:860-865, :1014-1016; evidence:  tally image vunpk fmt f16 8131, vpack f16 5868)
- **ISA.VC.009** `unproven` Math, unpack and pack FIFOs have vc.queue_depth [8] entries; fill/drain FIFOs have vc.dma_queue_depth [4]. Selected unpack/pack/fill/drain dispatch waits on full. With MQ_SKID zero math waits on full; current v9t6 enables MQ_SKID one, with two downstream skid entries, and math dispatch waits at FIFO occupancy at least queue_depth-2 [6], not physical FIFO full. (code: scripts/tcl/v9t5/00_config.tcl:16-24; scripts/tcl/v9t6/00_config.tcl:7; src/kohakutpu/vector2/v2_core.v:394-408, :425-453, :505-510, :519-535, :562-563; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.010** `silicon` `vc.dualq` [0]: one unpack queue and one pack queue. (code: src/kohakutpu/vector2/v2_core.v:48-52, :300-302, :414-415, :425-449; evidence:  v9t6 build defines no V2_DUALQ)
- **ISA.VC.011** `silicon` The core has `vc.descriptors` [8] address descriptors a0..a7, each a 40-bit base and `vc.descriptor_dims` [4] (stride, bound) dimensions. (code: src/kohakutpu/vector2/v2_core.v:44; src/kohakutpu/vector2/v2_agu.v:45-68; evidence:  tally image desc 1275 in 290)
- **ISA.VC.012** `silicon` Instruction memory holds `vc.imem_words` [1024] words; a RUN starts below `vc.run_reach` [512]. (code: src/kohakutpu/vector2/v2_core.v:38, :193, :249-261; src/kohakutpu/vector/vec_cu.v:175, :190, :543-558; evidence:  every silicon image RUN started below 512)
- **ISA.VC.013** `unproven` S3 through S14 are ordinary entries in the sixteen-entry 24-bit scalar array. S operands read S[reg & 15]. VSETI with to_k clear writes the following word low 24 bits to S[vd & 15]. (code: src/kohakutpu/vector2/v2_core.v:213, :333-339, :1764-1765, :1805-1809; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.014** `unproven` K operands use selector three and read K[reg & 3], including K3. Reset sets K3 zero. VSETI with to_k set writes its following word low 24 bits to K3. (code: src/kohakutpu/vector2/v2_core.v:173, :214, :333-339, :1734, :1805-1806; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.015** `unproven` The lane unit has vc.preds [4] 128-bit predicates. All use indexed reads and compare writes. Reads select sixteen bits at destination chunk*16; compare retirement updates selected destination-chunk bits only under its tail mask. (code: src/kohakutpu/vector2/v2_lanes.v:332-337, :366-368, :400-408; evidence: implementation inspection only; qualifying execution not established)

## 2. Core state and its lifetime

- **ISA.VC.020** `silicon` After core reset K0 = 0.0, K1 = 1.0 (0x3F8000), K2 = -1.0 (0xBF8000). The other reset values are ISA.VC.027. (code: src/kohakutpu/vector2/v2_core.v:191, :1723-1734; evidence:  silicon images use k0, k1, k2 as constants and never write them (kernels 0465d012, 0bbbc7fc))
- **ISA.VC.021** `silicon` A RUN restarts the DMA running offsets at 0 (ISA.VC.124) and keeps IMEM, so a resident program runs again by a RUN at its slot (ISA.VC.037). The rest of what a RUN clears and keeps is ISA.VC.028. (code: src/kohakutpu/vector2/v2_core.v:249-261, :1739-1748; src/kohakutpu/vector/vec_cu.v:543-558; evidence:  tally image vfill rel 2872, vdrain rel 1891 under `ainc` in 192 kernels; silicon kernel c965164a runs image `expand_9be27f3268_n0_vc0_0` twice (`run` at its lines 88 and 90))
- **ISA.VC.022** `unproven` RUN does not restore reset configuration. Its start branch does not assign VL, CHK, XB, unpack/pack pointers or increments, walk strides or descriptor increments. Software must establish the configuration it needs or rely on known retained state. (code: src/kohakutpu/vector2/v2_core.v:215-229, :1723-1748, :1775-1804; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.023** `silicon` Each accepted RUN clears the eight DMA running offsets. Relative VFILL/VDRAIN advances its descriptor offset by sign-extended eighteen-bit AINC. AINC retention is ISA.VC.028. (code: src/kohakutpu/vector2/v2_core.v:228-229, :1743-1748, :1784, :1801-1802; evidence:  tally image ainc 612 in 192)
- **ISA.VC.024** `unproven` Predicate storage has no reset initialization. Software must establish every relied-on predicate bit; compare initializes only destination-chunk bits enabled by its tail mask, not necessarily the whole register. (code: src/kohakutpu/vector2/v2_lanes.v:332-337, :374, :400-408; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.025** `unproven` The scalar array is not assigned in the core-reset branch, so reset establishes no defined initial scalar-register values. Software must initialize a scalar before relying on it. (code: src/kohakutpu/vector2/v2_core.v:213, :1723-1734, :1790, :1809; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.026** `unproven` GETSTK, VCFG selector eight, writes S[payload[3:0]] with E8M15 one if sticky is nonzero, otherwise zero, and requests clearing. Core reset and accepted RUN also clear sticky. EXP2D retirement accumulates overflow under its tail mask; reset/clear takes priority. (code: src/kohakutpu/vector2/v2_core.v:205-207, :743-758, :1743-1745, :1789-1792; src/kohakutpu/vector2/v2_lanes.v:409-413; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.027** `unproven` Core reset sets VL to VLMAX [128], CHK to 0x1111, XB zero, unpack/pack pointers and increments zero, walk strides s0=1 and s1=4, eight descriptor increments zero and K3 zero. These are reset values, not RUN initialization. (code: src/kohakutpu/vector2/v2_core.v:37, :221-224, :1723-1748; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.028** `unproven` Accepted RUN requests engine/queue soft reset, clears per-kind instruction counts and marks, cycle count and loop-active state, and zeros eight DMA running offsets. Lane reset clears sticky. RUN does not restore configuration defaults or reset descriptors; RX/CR counts and targets persist. (code: src/kohakutpu/vector2/v2_core.v:205-207, :394-452, :743-745, :1203-1206, :1517-1564, :1743-1748; src/kohakutpu/vector2/v2_lanes.v:409-413; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.029** `unproven` Predicate storage has no reset initialization. Compare retirement updates only selected destination-chunk bits under its tail mask. Software must establish every predicate bit it relies on. (code: src/kohakutpu/vector2/v2_lanes.v:366-368, :400-408; evidence: implementation inspection only; qualifying execution not established)

## 3. CU instructions: IMEM, DESC, RUN

- **ISA.VC.030** `silicon` A core takes three CU instructions, each a 256-bit `CU_INST` payload with op [255:252]: 1 IMEM, 2 DESC, 3 RUN. (code: src/kohakutpu/vector/vec_cu.v:77, :174-181, :539-562; evidence:  tally image desc 1275 in 290, `<image>` 381 RUNs in 290)
- **ISA.VC.031** `silicon` IMEM writes word [31:0] at instruction address {[242], [251:243]}. Payload bits [39:32] for a core of more than 32 registers are ISA.VC.004. (code: src/kohakutpu/vector/vec_cu.v:175, :543-548; src/kohakutpu/vector2/v2_core.v:249-261; evidence:  every silicon image loaded through IMEM below word 512)
- **ISA.VC.032** `silicon` With RW seven, zero extension bits above bit 31 make each register field name registers zero through 31 as its five-bit low field specifies. A 32-register encoding retains these selections on the 128-register core. (code: src/kohakutpu/vector2/v2_core.v:197-200, :253-257, :279-290; evidence:  the 32-register images of the silicon run executed on the v9t6 `RW` 7 core)
- **ISA.VC.033** `unproven` With IMEM_DEPTH 1024, payload bit 242 selects its upper half for loading. Fetch can advance into that half; CU RUN supplies only nine start bits and cannot directly start at words 512 through 1023. (code: src/kohakutpu/vector2/v2_core.v:38, :249-261, :578-591; src/kohakutpu/vector/vec_cu.v:175, :547, :558; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.034** `silicon` DESC selects descriptor [251:249] and field [248:246]. Its 40-bit value is {payload[68:63],payload[245:212]}. Field zero writes base; fields one through four write stride value[33:16] and bound value[15:0]. Other fields are ISA.VC.192. (code: src/kohakutpu/vector/vec_cu.v:176-180, :551-555; src/kohakutpu/vector2/v2_core.v:1203-1206; src/kohakutpu/vector2/v2_agu.v:49-68; evidence:  tally image desc 1275 in 290)
- **ISA.VC.035** `silicon` RUN supplies start PC from payload[251:243]. Normal VHALT clears busy and asserts halted; the CU returns the 32-bit busy-cycle count. Fault completion is ISA.VC.038. (code: src/kohakutpu/vector/vec_cu.v:557-573; src/kohakutpu/vector2/v2_core.v:1736-1745, :1817-1819; evidence:  tally image halt 381 in 290)
- **ISA.VC.036** `silicon` The vector CU executes IMEM, DESC and RUN only from C_IDLE. RUN passes through C_ACT and waits in C_RUNW for halted or fault, so IMEM and DESC do not execute underneath that running program. (code: src/kohakutpu/vector/vec_cu.v:539-578; evidence:  silicon packages send IMEM/DESC/RUN groups back to back to one core)
- **ISA.VC.037** `unproven` VLOOP/VSKIPZ compute addresses relative to current PC. Resident lowering relocates IMEM addresses and RUN PCs, omits resident program words, and suppresses unchanged descriptor writes. Slot start must fit RUN reach and the program must fit IMEM; relocation is not unrestricted. (code: src/kohakutpu/vector2/v2_core.v:572-581, :1811-1815; software/kohakutpu/compiler/crates/ktpu-l1/src/lower/imem.rs:58-72, :123-170; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.038** `unproven` Faulted RUN completes with exec_fault asserted and eight-bit fault code zero-extended to 32 bits. CU base selects SIG_FAULT and uses that execution result as argument. (code: src/kohakutpu/vector2/v2_core.v:1749-1756; src/kohakutpu/vector/vec_cu.v:160-162, :568-573; src/kohakuaccel/noc/endpoint/noc_cu_base.v:192-197; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.039** `unproven` Other four-bit CU opcodes take C_RET without IMEM/DESC load or RUN start, retiring with zero result and no execution fault. This is distinct from the core five-bit instruction opcode. (code: src/kohakutpu/vector/vec_cu.v:533-561, :575-578; src/kohakutpu/vector2/v2_core.v:278; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.192** `unproven` CU DESC fields five through seven reach the write port but do not update descriptor storage. Zero writes base; one through four write dimensions; there is no assignment for five through seven. (code: src/kohakutpu/vector/vec_cu.v:551-555; src/kohakutpu/vector2/v2_core.v:1205; src/kohakutpu/vector2/v2_agu.v:49, :61-68; evidence: implementation inspection only; qualifying execution not established)

## 4. Instruction words

- **ISA.VC.040** `silicon` Opcode [31:27] maps 0x00..0x12 to math, 0x13 VCFG, 0x14 VUNPK, 0x15 VPACK, 0x16 VSYNC, 0x1A VSETI, 0x1B VLOOP, 0x1C VBAR, 0x1D VFILL, 0x1E VDRAIN and 0x1F VHALT. VSETI consumes the following word as data. Other forms are ISA.VC.044-045; extension bits are ISA.VC.004. (code: software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:47-75, :108-120; src/kohakutpu/vector2/v2_core.v:279-290, :316, :513-566, :1764-1765, :1805-1809; evidence:  tally image `vl=` and `xb` modifiers (VCFG words), vunpk 8581, vpack 5868, vsync 7327, seti 320, loop 160, vbar 395, vfill 3076, vdrain 1891, halt 381)
- **ISA.VC.041** `silicon` Low-word math fields are vd[26:22], va[21:17], vb[16:12], vc[11:7], sa[6:5], sb[4:3], sc[2:1], om[0]. VCFG uses sel[26:23], payload[22:0]. VUNPK/VPACK uses reg[26:22], mode[21:20], n-1[19:17], cb[16:14], rel[13], q[12] and host off[11:0]; hardware uses the low LAW bits of offset, [8:0] at vc.l1_words [512]. (code: software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:282-295, :339-355, :413-528; src/kohakutpu/vector2/v2_core.v:279-314, :1682-1683; evidence:  tally image, every instruction listed here)
- **ISA.VC.042** `unproven` Host encoding zeros fields explicitly fixed zero in the selected format. Generic VCFG instead exposes all 23 payload bits and does not enforce specialized-format reserved bits. Host fixed fields are not RTL reserved-bit checks. (code: software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:242-265, :413-419, :465-513; software/kohakuaccel/compiler/crates/ka-isa/src/layout/format.rs:166-204; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.043** `unproven` Normal host format encoding returns Refusal for a supplied value outside its signed/unsigned field range rather than truncating or spilling. Vector variable fields use ISA.VC.043 for this check. The explicit fit_wraps mutant bypasses this normal behavior. (code: software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:19, :246-251; software/kohakuaccel/compiler/crates/ka-isa/src/layout/format.rs:53-77, :186-202; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.044** `unproven` Opcode 0x16 selects VMARK with waiter five, VWAIT with on seven; combining both faults F_SYNC. VWAIT uses waiter[26:24],on[23:21]=7,n[20:11],q[10],counter[9]. Host VMARK uses VSYNC fields with waiter five and marked/q zero. VSKIPZ 0x17 uses sreg[25:22],skip[7:0]; VPOST 0x19 uses dst_x[26:23],dst_y[22:19],n[15:0]. (code: software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:111-114, :423-474; src/kohakutpu/vector2/v2_core.v:300-311, :537-552; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.045** `unproven` VSETVL opcode 0x18 uses sreg[20:17] and assigns VL from scalar low eight bits, subject to F_VL validation. All thirty-two binary five-bit opcode values have math/control paths, so none reaches the default F_OPCODE arm; operand validation can still fault. (code: software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:475-478; src/kohakutpu/vector2/v2_core.v:283, :287, :316, :506-565, :1804; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.046** `unproven` Format::decode rejects mismatched fixed fields, but CoreFormats.set picks the first matching format and refuses only if none matches. A specialized VCFG with nonzero reserved bits can fall back to generic VCFG with variable selector/payload. RTL does not apply host fixed-zero checks: VHALT ignores low bits and CHK uses payload[15:0] without rejecting [22:16]. (code: software/kohakuaccel/compiler/crates/ka-isa/src/layout/format.rs:207-243, :306-323; software/kohakutpu/compiler/crates/ktpu-isa/src/unit/vector/core.rs:360-362, :413-419, :503, :538-569; src/kohakutpu/vector2/v2_core.v:514-518, :564, :1775-1776, :1817-1819; evidence: implementation inspection only; qualifying execution not established)

## 5. Math instructions

- **ISA.VC.050** `silicon` A math word names destination vd and sources a (va, sa), b (vb, sb), c (vc, sc); a selector is 0 V (vector register), 1 S (S[reg & 15]), 3 K (K[reg & 3]). (code: src/kohakutpu/vector2/v2_core.v:173, :279-292, :333-340; src/kohakutpu/vector2/v2_lanes.v:299-302; evidence:  silicon `vmul v4, k2, v19`, `vmul v20, s0, v4`, `vmax v4, v10, s2`)
- **ISA.VC.051** `unproven` Selector two in any math source slot faults F_SRC [11], even when the opcode does not consume that slot. Validation checks original selectors before unused-slot substitution. (code: src/kohakutpu/vector2/v2_core.v:188, :328-331, :502-510; evidence: implementation inspection only; qualifying execution not established)
- **ISA.VC.052** `silicon` An S or K operand's value is read at dispatch and applied to every lane and beat; a later VSETI does not change an op already dispatched. (code: src/kohakutpu/vector2/v2_core.v:333-340, :1691, :1699-1702, :646-647, :719-720; src/kohakutpu/vector2/v2_lanes.v:241-243, :283-285, :299-302; evidence:  silicon `seti s0 = ...` followed by `vmul vD, s0, vX` (kernel 0465d012))
- **ISA.VC.053** `silicon` Ordinary operand slots are a for vmov/vexp2/vlog2/vinv/vrsqrt; a,c for vadd; a,b for vmul/vmax; a,b,c for vsel. Dispatch substitutes K for unused b/c, so an unused slot acquires no vector read count. With om and XB.xc, c-consuming operations retain b. Other slots and physical RF routing are ISA.VC.063-071. (code: src/kohakutpu/vector2/v2_core.v:323-331, :631-635, :652-660, :1456-1463; src/kohakutpu/vector2/v2_lanes.v:251-275, :291-302; evidence:  silicon `vadd v8, v10, v12` (a, c), `vsel v13, v4, k0, v0` (a, b, c), `vmul v20, s0, v4`, `vinv`, `vexp2`, `vrsqrt`, `vlog2` (tally image))
- **ISA.VC.054** `silicon` vmov 0x00, vadd 0x03, vmul 0x05, vmax 0x08 and vsel 0x0A nominally compute a, a+c, a*b, b if a<b else a, and a if c[22:0] is nonzero else b. vexp2/vlog2/vinv/vrsqrt 0x0E..0x11 use polynomial paths for 2^a, log2(a), reciprocal and reciprocal square root. These E8M15 operations are subject to rounding and special-value handling, not exact-real or bitwise-copy guarantees. (code: src/kohakutpu/vector2/v2_core.v:318-319; src/kohakutpu/vector2/v2_alu.v:101-108, :160-171, :199-204, :219-271, :369-400, :480-549, :594-599, :737-787; evidence:  tally image vmul 7225 in 173, vadd 4441 in 178, vmov 1799 in 49, vsel 1272 in 47, vinv 664 in 35, vexp2 378 in 14, vmax 343 in 16, vrsqrt 131 in 23, vlog2 8 in 1)
