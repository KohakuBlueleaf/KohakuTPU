# ISA: the memory mover

What the stack relies on in the system node's memory mover
(`src/kohakuaccel/sysnode/mover/mm_mover.v`, walkers `mx_tdesc.v`) and its
transform slot (`src/kohakutpu/transform/xform_bank.v`): the command
registers, the walkers, the modes, the limits, the faults, and how a node
issues a move. Clause format, ids and evidence tags: [../README.md](../README.md).
MXFP7 itself is defined in [../numerics/formats.md](../numerics/formats.md).

Paths are relative to the repository root. `tally` is the statement
tally of the 455 kernels the v9t6 card ran; the silicon mover statements were
confirmed in the kernel sources of the v9t6 run (`move` / `move posted` blocks
of `copy`, `fill`, `quant`, `gt4`). Verilated card tests are in
`software/application/tests/test_l1_examples.py` (`test_l1`); RTL testbenches
are `tests/sysnode/mm_mover_tb.v` (`mm_mover_tb`) and
`tests/sysnode/mm_xform_tb.v` (`mm_xform_tb`), cited by section.

## 1. Parameters

- **ISA.MV.001** `silicon` Every transfer is one `die.word_bytes` [32]-byte word (AXI size 5, INCR bursts). (code: src/kohakuaccel/sysnode/mover/mm_mover.v:41,390-395; ktpu-isa/src/unit/mover.rs; doc: docs/spec/instruction-encoding.md:201-203; evidence: every silicon move)
- **ISA.MV.002** `RTL` Addresses are `die.noc.addr_bits` [40] bits, passed to the memory system unmasked ([39] aperture, [37:36] mesh), so a move reaches any mesh's DRAM and the L2 aperture. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:32-36,164-173; evidence: mm_mover_tb section 7 (:377))
- **ISA.MV.003** `silicon` A walker has up to `mover.levels` [6] levels; a level's count is 16 bits and its stride a signed 32-bit byte count. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:31-36; src/kohakuaccel/sysnode/mover/mm_mover.v:293-321; ktpu-isa/src/unit/mover.rs; evidence: silicon `quant w(h1+0, (13, 8192), (2, 128), (8, 1024), (2, 64), (4, 256), (2, 32)) -> ...` (6 levels))
- **ISA.MV.004** `unproven` An index list holds at most `mover.max_index` [2048] indices (`IDX_WORDS` 256 words of 8). (code: src/kohakuaccel/sysnode/mover/mm_mover.v:44-46,899-900; ktpu-isa/src/unit/mover.rs; evidence: none; test_l1 test_gather (:89) uses 16 indices and mm_mover_tb at most 20 (sections 5, 11), so no test fills the list)
- **ISA.MV.005** `silicon` A burst is at most `mover.burst_max` [128] words (4 KB) and never crosses a 4 KB page. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:35-36,57-58,256-259; evidence: silicon copies of 16384 words)
- **ISA.MV.006** `unproven` The configuration queue holds `mover.cfgq_depth` [64] register writes; ROOM reports that at least `mover.cfgq_margin` [8] more fit. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:20-24,66-68,222-236; evidence: none; mm_xform_tb section 5 (:353-383) queues one move's writes behind a running move, never filling the queue or reading ROOM low)
- **ISA.MV.007** `silicon` The stack keeps one move to at most 16384 words (the stack's move bound), so a move finishes inside the node's wait timeout at the slowest transform's rate; a larger operation is cut into whole moves. (code: ktpu-isa/src/unit/mover.rs; ktpu-l2/src/lower/mover.rs; evidence: silicon `fill w(dst+0, (16384, 32)) value=0 ew=16` sequences)

## 2. Command registers

- **ISA.MV.010** `silicon` The mover is commanded by 64-bit register writes at offsets 0x00 CTRL, 0x10 HDR, 0x18 DIM, 0x20 AXIS, 0x28 WINDOW, 0x40 IMM; the register is the offset with bits [2:0] dropped. 0x30 INDEX, 0x38 SEED and 0x50 ROW are ISA.MV.017; a write to any other register is ISA.MV.019. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:254,793-847; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:513-523; evidence: every silicon move)
- **ISA.MV.011** `RTL` Writes enter the configuration queue and are applied in order while the mover is idle; a write with GO starts a move and holds the queue until the move is done, so the next move's writes may be issued while one runs. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:20-24,222-253; evidence: mm_xform_tb section 5 (:354); silicon posted moves (tally fn move posted 119))
- **ISA.MV.012** `unproven` A write arriving with the queue full is dropped and latches fault F_CFGQ (9) until reset; every later move then reports F_CFGQ. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:231-232,251,871-873,878; evidence: none)
- **ISA.MV.013** `silicon` CTRL: mode [2:0], element width [4:3], flags [15:8], GO [16], fp32 index list [17]. The stack writes CTRL with GO last in each move. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:795-801; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:515; evidence: every silicon move)
- **ISA.MV.014** `silicon` HDR: walker select [0] (0 source, 1 destination), base [43:4] (40-bit byte address), level count [46:44]; on the source header, transform id [50:47] and transform mode [58:55]. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:802-817; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:516; evidence: every silicon move)
- **ISA.MV.015** `silicon` DIM: walker [0], level [3:1], count [19:4], signed stride [51:20]; it is staged and loaded into the walker by the next AXIS write: axis [1:0] (0 none, 1, 2), signed axis step [17:2]. The stack writes DIM then AXIS for every level. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:818-828; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:517-518; evidence: every silicon move)
- **ISA.MV.016** `RTL` WINDOW: walker [0], axis select [1] (0 axis 1, 1 axis 2), signed axis base [17:2], extent [33:18]. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:829-835; doc: docs/spec/control-registers.md:519; evidence: test_l1 test_pad (:59), test_mask (:65))
- **ISA.MV.017** `RTL` INDEX (offset 0x30): list base [39:0] (32-byte aligned), count [55:40]. ROW (0x50): pitch [31:0] bytes, row words [47:32]. SEED (0x38) [63:0]. IMM [31:0]. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:836-845; doc: docs/spec/control-registers.md:520-523; evidence: test_l1 test_gather (:89), test_generate (:83), test_fill (:74))
- **ISA.MV.018** `silicon` The stack writes both windows of every walker (extent 0 when unused) and the immediate or seed of every move that reads one. That registers keep their values across moves is ISA.MV.098. (code: ktpu-isa/src/unit/mover.rs; evidence: every silicon move writes both windows)
- **ISA.MV.019** `unproven` A MOVER register write at an offset other than those of ISA.MV.010 and ISA.MV.017 has no effect. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:254,793-847; evidence: none)
- **ISA.MV.098** `unproven` Every register keeps its value across moves: a window, immediate or seed not written for a move is the previous move's. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:89-111; evidence: none; the stack rewrites each before use, ISA.MV.018)

## 3. Walkers

- **ISA.MV.020** `silicon` A walker with n levels uses levels 0..n-1, level 0 outermost and level n-1 innermost; element (i_0 .. i_{n-1}) is at base + sum of i_k * stride_k. A count of 0 is ISA.MV.028. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:1-27,48,75-77,116-150; ktpu-isa/src/unit/mover.rs; evidence: silicon `copy w(src+0, (21, 64), (384, 1792), (2, 32)) -> w(dst+0, (16128, 32))`)
- **ISA.MV.021** `silicon` Strides may be negative or 0; a source stride of 0 reads one word repeatedly (broadcast). (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:15-24; doc: docs/spec/instruction-encoding.md:189-193; evidence: silicon `copy w(src+2432, (3, 10368), (14, 576), (14, 32), (5, -576), (5, -32)) -> ...`, `copy w(src+0, (400, 0), (16, 32)) -> ...`)
- **ISA.MV.022** `unproven` A level count field of 0 levels walks one element; 7 walks six levels. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:116-121; evidence: none; the stack writes 1..6, ktpu-isa/src/unit/mover.rs)
- **ISA.MV.023** `silicon` The stack writes every base and stride as a multiple of `die.word_bytes`, on both walkers. (code: ktpu-isa/src/unit/mover.rs; software/driver/kohakuaccel/driver/device/mover.py:64-66; evidence: every silicon move)
- **ISA.MV.024** `RTL` A destination element whose address is not word aligned faults F_ALIGN (6). That the elements before it are written is ISA.MV.029. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:265,432,964,1018-1019; evidence: mm_mover_tb section 6 (:361-371), a one-element move)
- **ISA.MV.025** `unproven` A misaligned source address is not checked by the mover. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:428-440; software/driver/tests/test_mover.py:144-145; evidence: none)
- **ISA.MV.026** `RTL` Bound axes: each level may add its axis step to axis 1 or 2; an element is inside when, for each axis whose window extent is nonzero, 0 <= axis base + sum of i_k * astep_k < extent. An extent of 0 disables the axis. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:7-13,286-292; evidence: test_l1 test_pad (:59), test_mask (:65); mm_mover_tb section 2 (:268))
- **ISA.MV.027** `RTL` A source element outside its window issues no read and supplies the immediate, replicated by element width (ISA.MV.041); a destination element outside its window is not written, and the walk still steps. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:6-7,428-440; doc: docs/spec/instruction-encoding.md:189-193; evidence: test_l1 test_pad (:59) (fp16 1.0 pairs padded), test_mask (:65))
- **ISA.MV.028** `unproven` A level's count of 0 reads as 1. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:48,75-77; evidence: none; the stack writes counts of at least 1)
- **ISA.MV.029** `unproven` A move that faults F_ALIGN at a destination element has written the elements before it. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:964,1018-1019; evidence: none; mm_mover_tb section 6 faults a one-element move)

## 4. Modes

- **ISA.MV.030** `silicon` Mode 0 COPY: the destination walker defines the iteration space and the source walker steps alongside it, one word per element. The stack gives both walkers the same element count. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:1-3,286-289; ktpu-l1/src/lower/node/mover.rs; doc: docs/spec/control-registers.md:525; evidence: tally fn copy 1432 in 258)
- **ISA.MV.031** `RTL` A transpose of 32-byte words is a COPY whose source walk visits the words in the transposed order. (code: software/language/kohakutpu/language/examples/l1/mover/transpose.ktpu; doc: docs/spec/instruction-encoding.md:183; evidence: test_l1 test_transpose (:52), test_l2_mover_gather_and_transpose (:383))
- **ISA.MV.032** `unproven` Mode 1 TRANSPOSE faults F_MODE (4) at GO and moves nothing. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:896-897; software/driver/kohakuaccel/driver/device/mover.py:78; evidence: none)
- **ISA.MV.033** `RTL` Mode 2 GATHER: the destination walker defines the iteration space; destination row r (ROW.words consecutive elements) is read from source base + index[r] * pitch, words consecutive. The source header supplies only its base. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:3-4,421,428-431,745-746; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:617-631; evidence: test_l1 test_gather (:89); mm_mover_tb sections 5, 8, 11 (:333, :415, :531))
- **ISA.MV.034** `RTL` Mode 3 GENERATE: no source; each destination word is a counter-based PRNG output keyed by SEED and the word's absolute destination address, so any split of a walk writes the same bytes. Element width: ISA.MV.044. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:353-365,1117-1148; ktpu-isa/src/unit/mover.rs; doc: docs/spec/instruction-encoding.md:185; evidence: test_l1 test_generate (:83); mm_mover_tb section 4 (:298))
- **ISA.MV.035** `silicon` Mode 4 FILL: no source; every destination element is written with the immediate replicated by element width. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:367-387,437; ktpu-isa/src/unit/mover.rs; evidence: silicon `fill w(h1+0, (192, 32)) value=0` (W32) and `value=0 ew=16`)
- **ISA.MV.036** `RTL` FILL with a nonzero immediate at each element width writes the patterns of ISA.MV.041. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:367-387; evidence: test_l1 test_fill (:74), 0x12345678 at ew 8, 16, 32; mm_mover_tb section 3 (:288))
- **ISA.MV.037** `silicon` Mode 5 XFORM: a COPY whose read return passes through the transform slot (section 6). (code: src/kohakuaccel/sysnode/mover/mm_mover.v:12-18,269-281; doc: docs/spec/control-registers.md:578-615; evidence: tally fn quant 172 in 25, gt4 442 in 38)
- **ISA.MV.038** `RTL` Mode 6 SCATTER: the source walker defines the iteration space; source row r (ROW.words elements) is written at destination base + index[r] * pitch, words consecutive; the destination header supplies only its base. Repeated indices: ISA.MV.045. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:283-286,430-431,746; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:624-633; evidence: test_l1 test_scatter (:409); mm_mover_tb section 9 (:445))
- **ISA.MV.039** `RTL` A SCATTER whose destination base or pitch is not a multiple of 32 faults F_ALIGN (6) at GO and writes nothing. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:901-903; evidence: mm_mover_tb section 9 (:487-490))
- **ISA.MV.040** `unproven` Mode 7 runs as a COPY. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:130-132,436-440; doc: docs/spec/control-registers.md:526-527; evidence: none)
- **ISA.MV.041** `RTL` Element width: 0 W8 replicates IMM[7:0] 32 times, 1 W16 IMM[15:0] 16 times, 2 W32 IMM[31:0] 8 times across the word; it applies only to the immediate (FILL and padding). Width 3 faults F_EWIDTH (5) at GO. The reset width is ISA.MV.046. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:367-387,892-893; ktpu-isa/src/unit/mover.rs; evidence: test_l1 test_fill (:74); mm_mover_tb section 6 (:352-359))
- **ISA.MV.042** `silicon` flags [3] coalesces consecutive writes into bursts; flags [7:5] caps a burst at 2^(n-1) words, 0 meaning `mover.burst_max`. The stack sets [3] and leaves [7:5] 0 unless told. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:29-30,256-260; ktpu-isa/src/unit/mover.rs; ktpu-l1/src/lower/node/mover.rs; evidence: every silicon move, flags 0x08)
- **ISA.MV.043** `unproven` A burst cap flags[7:5] of 1..7 limits bursts as ISA.MV.042 states. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:258-259; evidence: none)
- **ISA.MV.044** `unproven` GENERATE does not read the element width. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:353-365; evidence: none; test_generate and mm_mover_tb section 4 (`go(3'd3, 2'd1)`) each generate at one element width and compare nothing across widths)
- **ISA.MV.045** `unproven` A SCATTER with repeated indices writes the same row again, in list order. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:283-286,430-431; evidence: none; test_scatter draws indices without replacement and mm_mover_tb's lists (sections 9, 11) are permutations)
- **ISA.MV.046** `unproven` After reset the element width is W16. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:702; evidence: none; the stack writes the width in every CTRL)

## 5. Index lists

- **ISA.MV.050** `RTL` An index list is INDEX.count 32-bit indices, eight to a word, index r in bits [32(r mod 8)+31 : 32(r mod 8)] of word r div 8, loaded whole before the first row. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:323-341,349-350,917-944; doc: docs/spec/control-registers.md:619-622,635-636; evidence: test_l1 test_gather (:89), test_scatter (:409))
- **ISA.MV.051** `RTL` CTRL[17] clear reads the indices as u32; set reads them as fp32, each of which must be +0, -0 or a positive integer below 2^31, else fault F_INDEX (10) when its row is reached, after the rows before it are written. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:190-191,409-418,964-971,1034-1041; doc: docs/spec/control-registers.md:642-647; evidence: test_l1 test_gather (:89) (u32 and fp32); mm_mover_tb sections 10, 11 (:494, :525, :580))
- **ISA.MV.052** `unproven` An index count above `mover.max_index` faults F_IDXLEN (1) at GO. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:899-900; evidence: none)
- **ISA.MV.053** `unproven` The stack writes an index count of at least 1 and row words of at least 1, and cuts a gather or scatter past one move's index list or row words into several moves. (code: ktpu-l1/src/lower/node/mover.rs; ktpu-isa/src/unit/mover.rs; ktpu-l2/src/lower/mover.rs; evidence: none on silicon or RTL; a software test checks the cut, ktpu-l2/tests/ported.rs)
- **ISA.MV.054** `unproven` Index list base must be 32-byte aligned; the mover reads from the base's word. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:336-340,905; ktpu-isa/src/unit/mover.rs; evidence: none for a misaligned base)

## 6. The transform slot

- **ISA.MV.060** `silicon` An XFORM move names its occupant on the source header: transform id [50:47], transform mode [58:55] (opaque to the mover, passed to the occupant). (code: src/kohakuaccel/sysnode/mover/mm_mover.v:812-816,889-891; doc: docs/spec/control-registers.md:584-592; evidence: tally fn quant 172, gt4 442)
- **ISA.MV.061** `silicon` In XFORM the source walker counts source words and defines the iteration space; the destination walker steps once per entry, and each entry's output words are written consecutively from the destination element's address. An entry is the occupant's IN_BITS / 256 source words. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:12-18,269-289; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:594-609; evidence: silicon `quant w(h1+0, (192, 32)) -> w(q+0, (24, 128)) bpack` (192 source words, 24 entries of 4 words))
- **ISA.MV.062** `silicon` The stack gives an XFORM source walk a whole number of entries and element width W16. (code: ktpu-isa/src/unit/mover.rs; ktpu-l1/src/lower/node/mover.rs; evidence: every silicon quant and gt4)
- **ISA.MV.063** `silicon` KohakuTPU's slot (id 0, the bypass, is ISA.MV.064): id 1 QUANT, 2048 bits (8 words) of FP16 in and 4 MXFP7 words out, transform mode [0] selecting the B packing; id 2 GT4, 4 words in and 4 out, out word i granule w = in word w granule i (64-bit granules). (code: src/kohakutpu/transform/xform_bank.v:1-17,72-77,92-138; ktpu-isa/src/unit/mover.rs; doc: docs/spec/control-registers.md:606-609; evidence: silicon `quant ... bpack`, `quant ...` (A packing), `gt4 w(x+0, (100, 2048), (16, 32), (4, 512)) -> ...`)
- **ISA.MV.064** `RTL` The bypass occupant (id 0) takes 4 words in and passes them out unchanged. (code: src/kohakutpu/transform/xform_bank.v:1-17,92-138; evidence: mm_xform_tb section 5 (:359-381), move B through id 0 checked word for word against its source; sections 1 and 2 run id 1)
- **ISA.MV.065** `silicon` The stack walks a QUANT entry as `mover.xform.quant_lanes` [4] rows of `mover.xform.quant_values` [32] FP16 values, two words a row, out as one word a row; and a GT4 group as `mover.xform.gt4_rows` [4] consecutive source words of `mover.xform.gt4_cols` [16] FP16 values, transposed as a 4 x 4 array of `mover.xform.gt4_granule_bits` [64]-bit granules. (code: ktpu-l2/src/lower/mover.rs; software/rust/crates/ktpu-isa/src/unit/mover.rs `MoverIsa::new`; RTL src/kohakutpu/transform/xform_bank.v:5-6,28,32-33,104-113; src/kohakutpu/transform/mx_quant.v:7-10,71; evidence: silicon quant walks with innermost (2, 32) and gt4 walks with (4, 512) / (4, 64) levels)
- **ISA.MV.066** `RTL` The occupant's geometry is readable at its register 1: out words [23:16], in bits [15:0]. An id with no occupant is ISA.MV.071. (code: src/kohakutpu/transform/xform_bank.v:158-169; doc: docs/spec/control-registers.md:565-569; evidence: test_l1 test_memops (:110), `4 << 16 | 2048` for QUANT)
- **ISA.MV.067** `unproven` An XFORM with an id naming no occupant fails with F_XFORM (8); the occupant's fault bit holds until a write to its register 0. (code: src/kohakutpu/transform/xform_bank.v:141-156; src/kohakuaccel/sysnode/mover/mm_mover.v:867-870; evidence: none)
- **ISA.MV.068** `unproven` An XFORM source element outside a window faults F_XPAD (7): a transform move takes no bound axis. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:433-435,1021-1022; doc: docs/spec/control-registers.md:611-613; evidence: none)
- **ISA.MV.069** `unproven` An XFORM whose occupant reports 0 source words or 0 depth faults F_MODE (4) at GO. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:894-895; evidence: none)
- **ISA.MV.070** `silicon` A transform applies only to the mover's read return; no fetch or drain selects one. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:812-816; doc: docs/spec/instruction-encoding.md:147,168-169; evidence: silicon quant moves; see Conflicts item 2)
- **ISA.MV.071** `unproven` The geometry register of an id with no occupant reads 0. (code: src/kohakutpu/transform/xform_bank.v:158-169; evidence: none; test_memops reads the QUANT occupant only)

## 7. Completion and faults

- **ISA.MV.080** `silicon` A move is done when every write it issued has retired and every entry it began has left the slot; the done count then advances by 1. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:1080-1094; evidence: silicon MOVER steps waited on move completion)
- **ISA.MV.081** `RTL` A faulted move's fault code holds after it, and the next GO replaces it. The rest of the fault behaviour is ISA.MV.084. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:862-866,877-878; evidence: mm_mover_tb section 6 (:352-371): a width-3 move reads fault 5, the next move reads fault 6)
- **ISA.MV.082** `silicon` A move that completes reports fault 0 (none). The other codes are ISA.MV.085 and ISA.MV.086. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:134-137; software/driver/kohakuaccel/driver/device/mover.py:73-87; doc: docs/spec/control-registers.md:529-533,656; evidence: silicon moves completed with fault 0)
- **ISA.MV.083** `silicon` The node reads MVSTAT: room [33], busy [32], fault [31:28], moves done [27:0]. The host's AUX_STAT is ISA.MV.087. (code: software/firmware/kohakuaccel/package/interp.c:552-575; doc: docs/spec/control-registers.md:649-661; evidence: silicon MOVER steps polled MVSTAT)

## 8. How a node issues moves

- **ISA.MV.090** `silicon` A package's MOVER step carries register writes as 256-bit payloads of two (register, 64-bit value) pairs; a register of all ones is skipped. The node writes them in order to the mover. (code: ktpu-l0/src/build/mod.rs; software/firmware/kohakuaccel/package/interp.c:610-639; evidence: tally fn move 411 in 292)
- **ISA.MV.091** `unproven` A MOVER-step register of 0x80 or above, or not a multiple of 8, fails the package with NO_REACH. (code: software/firmware/kohakuaccel/package/interp.c:625-627; evidence: none)
- **ISA.MV.092** `silicon` The node reads ROOM before every `mover.cfgq_margin` writes, so it never overflows the configuration queue. (code: software/firmware/kohakuaccel/package/interp.c:594-608,628-630; evidence: every silicon MOVER step (tally fn move 411) wrote through this path)
- **ISA.MV.093** `silicon` A write to register 0 with bit 16 set counts one GO. A MOVER step without `posted` then waits until every move the package started is done and the mover is idle; a posted step continues, and a later MWAIT n waits until n of the package's moves (counted from its start) are done. (code: software/firmware/kohakuaccel/package/interp.c:577-592,632-638; ktpu-l0/src/build/mod.rs; ktpu-l1/src/lower/node/mover.rs; evidence: tally fn move posted 119)
- **ISA.MV.094** `unproven` A mover wait fails the package with MOVER_FAULT when the mover reports a fault, and with TIMEOUT (wait MOVER) only when no move finishes for one timeout: the bound is on progress, not on the step. (code: software/firmware/kohakuaccel/package/interp.c:544-575; evidence: none)
- **ISA.MV.095** `silicon` In L1 text a move is a `move` block (or `T = move posted`, waited by `wait moves T`) of `copy`, `quant`, `gt4`, `fill` statements over walks `w(BASE, (COUNT, STRIDE), ...)`, levels outermost first. The other statements and walk terms are ISA.MV.096 and ISA.MV.097. (code: ktpu-l1/src/lower/node/mover.rs; evidence: silicon `move` / `mv0 = move posted` blocks and `wait moves`)
- **ISA.MV.096** `RTL` A move block also takes `gen`, `gather` and `scatter` statements and walk levels with a bound axis `(COUNT, STRIDE, AXIS, ASTEP)` and windows `win1=(B, E)`, `win2=(B, E)`; a walk base may come from a register and is patched into the payload at run time. (code: ktpu-l1/src/lower/node/mover.rs; evidence: test_l1 test_generate (:83), test_gather (:89), test_scatter (:409), test_pad (:59), test_mask (:65), test_loop_runs_a_count_from_memory (:101) (`copy w(x + r3, ..)`))
- **ISA.MV.097** `unproven` A move block takes `xform` statements; a count, immediate, seed, index base, index count, pitch or row words may come from a register and is patched into the payload at run time. (code: ktpu-l1/src/lower/node/mover.rs; evidence: none naming them)
