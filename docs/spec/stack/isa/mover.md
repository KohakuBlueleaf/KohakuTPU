# ISA: the memory mover

What the stack relies on in the system node's memory mover
(`src/kohakuaccel/sysnode/mover/mm_mover.v`, walkers `mx_tdesc.v`) and its
transform slot (`src/kohakutpu/transform/xform_bank.v`): the command
registers, the walkers, the modes, the limits, the faults, and how a node
issues a move. Clause format, ids and evidence tags: [../README.md](../README.md).
MXFP7 itself is defined in [../numerics/formats.md](../numerics/formats.md).

Paths are relative to the repository root. `tally` is the statement
tally of the 455 kernels the v9t6 card ran; the silicon mover statements were
confirmed in the kernel sources of the v9t6 run (`move` / `move posted` blocks
of `copy`, `fill`, `quant`, `gt4`). RTL testbenches are `tests/sysnode/mm_mover_tb.v` (`mm_mover_tb`) and
`tests/sysnode/mm_xform_tb.v` (`mm_xform_tb`), cited by section.

## 1. Parameters

- **ISA.MV.001** `silicon` Each AXI data beat is one die.word_bytes [32]-byte word. ARSIZE/AWSIZE are five and ARBURST/AWBURST select INCR. A burst may contain multiple beats. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:396-399; evidence:  every silicon move)
- **ISA.MV.002** `RTL` The 40-bit mover AXI address path preserves mesh/aperture high bits rather than aliasing them onto local DRAM. This does not guarantee successful routing to every aperture. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:299-325, :966-967, :993-994, :1010-1012, :1130; evidence: tests/sysnode/mm_mover_tb.v:373-400 checks high bits and nonempty traffic)
- **ISA.MV.003** `silicon` Each walker has mover.levels [6] dimensions with unsigned 16-bit counts and signed 32-bit byte strides. Zero-count behavior is ISA.MV.028. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:299-325; src/kohakuaccel/sysnode/mover/mx_tdesc.v:31-49, :99-103; evidence:  silicon `quant w(h1+0, (13, 8192), (2, 128), (8, 1024), (2, 64), (4, 256), (2, 32)) -> ...` (6 levels))
- **ISA.MV.004** `unproven` The index buffer capacity is mover.max_index [2048] 32-bit indices, from 256 words of eight indices. GATHER/SCATTER reject a count above capacity at GO, subject to earlier validation faults. The typed encoder accepts counts only from one through the machine maximum. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:44-46, :332-356, :898-906; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:477-490; evidence: implementation inspection only; matching historical execution not established)
- **ISA.MV.005** `RTL` Ordinary aligned read/write runs are bounded by the selected cap and the remaining words in the 4-KB page. Default cap is mover.burst_max [128]. Index reads split at page boundaries into at most 128-word requests. Transform output uses a separate OUT_WORDS burst path, not this ordinary run rule. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:342-347, :537-549, :684-688; evidence: tests/sysnode/mm_mover_tb.v:99-120,403-409)
- **ISA.MV.006** `unproven` The configuration FIFO holds mover.cfgq_depth [64] writes. ROOM is the predicate occupancy <= mover.cfgq_depth - mover.cfgq_margin [64 - 8]. Configuration inputs also pass through a staging register before FIFO insertion, so ROOM describes FIFO occupancy rather than independently accounting for all upstream writes in flight. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:211-258; evidence: implementation inspection only)
- **ISA.MV.007** `unproven` The compiler defines a 16384-word move-cut target. L2 copy lowering cuts walks using this target and may reduce it to preserve complete DRAM-line groups. It is neither a universal typed-encoder limit nor a hardware completion-time guarantee. (code: software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:37, :469-534; software/kohakutpu/compiler/crates/ktpu-l2/src/lower/mover.rs:62-87; evidence: implementation inspection only; matching historical execution not established)

## 2. Command registers

- **ISA.MV.010** `silicon` The mover accepts 64-bit configuration writes at byte offsets 0x00 CTRL, 0x10 HDR, 0x18 DIM, 0x20 AXIS, 0x28 WINDOW and 0x40 IMM. INDEX, SEED and ROW are ISA.MV.017. Register decoding clears bits [2:0]. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:213-219, :260, :799-853; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:13-21; evidence:  every silicon move)
- **ISA.MV.011** `RTL` Accepted configuration writes enter a FIFO and are applied in order while the mover is idle. Applying CTRL with GO set stops further dequeue through startup and execution; later writes can queue during execution, subject to capacity. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:222-258, :801-806, :883-920; evidence: tests/sysnode/mm_xform_tb.v:353-381 checks queued moves and completion count)
- **ISA.MV.012** `unproven` A configuration write arriving while the queue is full is dropped and sets the queue-overflow latch until reset. Overflow sets the reported fault to F_CFGQ (9); each subsequent GO initially selects F_CFGQ, but the GO validation checks can replace it with another fault. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:231-256, :877-909; evidence: no named RTL test or card run established for overflow and fault precedence)
- **ISA.MV.013** `silicon` CTRL contains mode [2:0], element width [4:3], flags [15:8], GO [16] and fp32-index selection [17]. The normal typed encoder emits CTRL with GO as the final write of a move. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:801-806; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:24-33, :521-534; evidence:  every silicon move)
- **ISA.MV.014** `silicon` For the 40-bit address format, HDR contains source/destination select [0], byte base [43:4] and level count [46:44]. Source HDR loads transform id [50:47] and mode [58:55]; destination HDR leaves those fields unchanged. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:42, :60-61, :299-326, :808-822, :895-897; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:40-43, :420-425; evidence:  every silicon move)
- **ISA.MV.015** `silicon` DIM stages walker select [0], level [3:1], count [19:4] and signed byte stride [51:20]. AXIS supplies selector [1:0] and signed step [17:2] and loads the staged dimension. The normal encoder emits DIM immediately followed by AXIS. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:299-326, :824-834; src/kohakuaccel/sysnode/mover/mx_tdesc.v:45-51, :99-103; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:427-443; evidence:  every silicon move)
- **ISA.MV.016** `RTL` WINDOW contains walker select [0], axis select [1], signed axis base [17:2] and unsigned extent [33:18]. A write loads the selected bound axis of the selected walker. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:299-326, :835-840; src/kohakuaccel/sysnode/mover/mx_tdesc.v:57-60, :109-111; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:445-451; evidence: tests/sysnode/mm_mover_tb.v:162-164,267-285)
- **ISA.MV.017** `RTL` INDEX contains list byte base [39:0] and count [55:40]. ROW contains byte pitch [31:0] and row-word count [47:32]. SEED loads 64 bits and IMM loads [31:0]. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:842-850, :911-913; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:477-514; evidence: tests/sysnode/mm_mover_tb.v:289-295,299-329,334-346)
- **ISA.MV.018** `silicon` For each supplied walker, the normal encoder emits both WINDOW writes before final CTRL. Register persistence is ISA.MV.098. (code: software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:144-153, :445-451, :469-475, :506-534; evidence:  every silicon move writes both windows)
- **ISA.MV.019** `unproven` Configuration addresses are decoded after clearing their low three bits. An address whose resulting register offset is absent from the register case has no register-specific effect when applied, but the write still occupies the configuration FIFO and can contribute to overflow. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:231-256, :260, :799-853; evidence: implementation inspection only)
- **ISA.MV.098** `unproven` Walker descriptor base, dimension and bound-axis registers persist until reset or a corresponding configuration write; GO restarts the walk indices and partial sums, not the descriptor. Immediate and seed likewise persist until reset or their register writes. This persistence does not apply to transient control such as the GO pulse or to per-move counters. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:86-113, :171-189; src/kohakuaccel/sysnode/mover/mm_mover.v:708-716, :799-850, :883-889; evidence: implementation inspection only)

## 3. Walkers

- **ISA.MV.020** `silicon` A walker enables levels zero through n-1, with zero outermost. For addresses without arithmetic overflow, it walks base plus the sum of each dimension index times its byte stride. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:116-150, :173-189, :208-224; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:427-443; evidence:  silicon `copy w(src+0, (21, 64), (384, 1792), (2, 32)) -> w(dst+0, (16128, 32))`)
- **ISA.MV.021** `silicon` Strides are signed 32-bit byte quantities and may be negative or zero. Zero stride repeats addresses along that dimension while other dimensions can change them. COPY reads valid repeated source addresses. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:125-127, :180-189, :208-224; src/kohakuaccel/sysnode/mover/mm_mover.v:434-446, :985-995; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:406-414; evidence:  silicon `copy w(src+2432, (3, 10368), (14, 576), (14, 32), (5, -576), (5, -32)) -> ...`, `copy w(src+0, (400, 0), (16, 32)) -> ...`)
- **ISA.MV.022** `unproven` A raw walker level count of zero makes all dimensions inert and presents one element at its base. A count above mover.levels [6], including encoded seven, enables all physically instantiated levels rather than a seventh level. The typed encoder refuses dimension lists outside 1..mover.levels. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:116-165, :171-189, :332-355; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:395-405; evidence: implementation inspection only)
- **ISA.MV.023** `unproven` For each supplied walker the normal typed encoder rejects bases and strides not divisible by die.word_bytes [32]. The explicit rul.050/unaligned mutant bypasses this check. This validation does not guarantee that raw configuration writes are aligned. (code: software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:395-414, :469-475; evidence: implementation inspection only; named benches do not establish all added overflow, masking or per-mode validation cases)
- **ISA.MV.024** `RTL` An in-window destination element with a non-word-aligned address records F_ALIGN when processed. SCATTER GO-time checking is ISA.MV.039 and prior traffic is ISA.MV.029. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:434-446, :965-971, :1024-1029; evidence: tests/sysnode/mm_mover_tb.v:361-371)
- **ISA.MV.025** `unproven` The mover has no source-alignment fault check. Ordinary reads use the walker source address and GATHER uses its computed row base unchanged. Destination alignment is tested separately. The typed host encoder rejects unaligned walker bases and strides and unaligned row pitches unless the explicit alignment mutant is enabled. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:434-446, :966-970, :993-995; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:406-414, :493-504; evidence: implementation inspection only)
- **ISA.MV.026** `RTL` Levels selecting axis one or two contribute axis-step partial sums to that axis. An element is in-window when each enabled axis position is nonnegative and below its extent; extent zero disables the axis. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:125-127, :173-189, :257-297; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:427-451; evidence: tests/sysnode/mm_mover_tb.v:267-285)
- **ISA.MV.027** `RTL` In COPY, an aligned in-window destination whose source is outside its window receives the immediate replicated by element width, without a source read. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:374-393, :434-446, :693-698, :985-1029; evidence: tests/sysnode/mm_mover_tb.v:267-285)
- **ISA.MV.028** `unproven` A level's count of 0 reads as 1 in the walker. The encoder accepts a zero count: its unsigned 16-bit field check does not impose a positive lower bound, and the L1 reader passes constant counts through. (code: src/kohakuaccel/sysnode/mover/mx_tdesc.v:99-100, software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:321-332, :434-438, software/kohakutpu/compiler/crates/ktpu-l1/src/lower/node/mover.rs:533-546; evidence: implementation inspection only)
- **ISA.MV.029** `unproven` A valid destination element with a non-word-aligned address is classified K_SKIP and records F_ALIGN when processed. The move then flushes its previously accumulated read/write runs and waits for outstanding traffic before returning idle. Earlier non-skipped elements can have writes pending at fault detection; they are not rolled back. A destination outside its enabled window is skipped without triggering this alignment fault. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:434-446, :965-971, :1024-1031, :1071-1104; evidence: implementation inspection only)

## 4. Modes

- **ISA.MV.030** `silicon` Mode zero COPY uses destination-walker termination and advances the source alongside it. Ordinary unmasked elements copy one die.word_bytes [32]-byte word. Masking and padding are ISA.MV.027. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:289-325, :434-446, :965-971, :1030-1062; evidence:  tally fn copy 1432 in 258)
- **ISA.MV.031** `RTL` COPY can transpose whole die.word_bytes [32] words by choosing different source and destination traversal orders. It does not transpose elements within a word and does not use mode one TRANSPOSE. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:289-325, :434-446; evidence: tests/sysnode/mm_mover_tb.v:250-264 checks every transposed output word)
- **ISA.MV.032** `unproven` Mode 1 TRANSPOSE enters I_FAULT at GO with F_MODE (4), before starting a walk. Element-width code 3 takes precedence and instead reports F_EWIDTH (5). I_FAULT drops the transform request and returns idle without incrementing the done counter. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:130-137, :883-903, :1094-1104; evidence: implementation inspection only)
- **ISA.MV.033** `RTL` Mode two GATHER uses destination-walker termination. For nonzero ROW.words, each row selects consecutive source words at source base plus index times ROW.pitch. Source walker dimensions do not select those indexed addresses. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:289-325, :412-446, :748-752, :965-978, :1030-1062; evidence: tests/sysnode/mm_mover_tb.v:333-346,415-434,531-549)
- **ISA.MV.034** `RTL` Mode three GENERATE reads no source data and derives output from SEED and absolute destination address. Splitting a walk while preserving seed and addresses preserves output. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:359-370, :434-446, :547, :614-630, :1119-1153; src/kohakuaccel/sysnode/mover/mm_prng.v:37-44, :70-75, :84-118; evidence: tests/sysnode/mm_mover_tb.v:298-329)
- **ISA.MV.035** `silicon` Mode four FILL reads no source data and writes the immediate replicated by element width to each non-skipped destination element. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:373-393, :434-446, :614-616, :987-1031; evidence:  silicon `fill w(h1+0, (192, 32)) value=0` (W32) and `value=0 ew=16`)
- **ISA.MV.036** `unproven` FILL replicates the low eight, sixteen or thirty-two immediate bits for W8, W16 or W32, respectively, including nonzero immediates. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:373-393, :614-616; evidence: implementation inspection only; named benches do not establish all added overflow, masking or per-mode validation cases; historical af7c1bb:software/application/tests/test_l1_examples.py:74-80 defines a three-width fill test, but the full historical execution chain was not established)
- **ISA.MV.037** `silicon` Mode five XFORM feeds mover read-return words through the transform slot and writes its output. It terminates from the source walker and advances the destination by entry. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:275-295, :483-498, :684-688, :760-780; evidence:  tally fn quant 172 in 25, gt4 442 in 38)
- **ISA.MV.038** `RTL` Mode six SCATTER uses source-walker termination. For nonzero ROW.words, each source row is written as consecutive words at destination base plus index times ROW.pitch; destination walker dimensions do not select those addresses. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:289-325, :412-446, :748-752, :907-909, :965-978, :1030-1062; evidence: tests/sysnode/mm_mover_tb.v:445-484,552-564)
- **ISA.MV.039** `RTL` At GO, SCATTER rejects an unaligned destination base with F_ALIGN (6), without starting that move. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:898-918; evidence: tests/sysnode/mm_mover_tb.v:487-490)
- **ISA.MV.040** `unproven` Mode 7 runs as a COPY. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:130-132,442-446; doc: docs/spec/control-registers.md:526-527; evidence: none)
- **ISA.MV.041** `RTL` Width code one repeats IMM[15:0] sixteen times for immediate FILL and padding. Width code three is rejected at GO with F_EWIDTH (5). Reset width is ISA.MV.046. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:373-393, :434-446, :614-616, :898-903; evidence: tests/sysnode/mm_mover_tb.v:267-295,352-359)
- **ISA.MV.042** `silicon` Flags[3] enables ordinary write-run coalescing. The normal emitted default enables it with flags[7:5] zero, selecting mover.burst_max [128]. Nondefault caps are ISA.MV.043. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:262-266, :342-347, :545-549, :684-688; software/kohakutpu/compiler/crates/ktpu-l1/src/lower/node/mover.rs:268-272; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:456-465; evidence:  every silicon move, flags 0x08)
- **ISA.MV.043** `unproven` For nonzero flags[7:5], the ordinary run accumulator uses cap=2^(flags[7:5]-1), further limited by remaining words in the current page. This cap applies to ordinary read/write run extension; it is not a universal transform-output burst cap, because transform commands bypass the ordinary write-run accumulator. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:264-265, :537-549, :1001-1003; evidence: implementation inspection only)
- **ISA.MV.044** `unproven` GENERATE's PRNG uses the seed and counter, not the element width; GO nevertheless rejects element-width code 3 with F_EWIDTH, including in GENERATE mode. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:359-370, :898-899; evidence: no card or named RTL comparison across element widths established)
- **ISA.MV.045** `unproven` SCATTER consumes indexed rows in list order. Repeated indices produce repeated writes to the same row addresses, with commands and data issued in that order. This is an issue-order contract, not an independent guarantee about memory completion or visibility. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:352-357, :434-437, :591-610, :684-688, :965-975, :1003-1017, :1032-1062, :1114-1137; evidence: implementation inspection only; historical matching execution not established)
- **ISA.MV.046** `unproven` After reset the element width is W16. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:708; evidence: none; the stack writes the width in every CTRL)

## 5. Index lists

- **ISA.MV.050** `RTL` For nonzero accepted INDEX.count, the mover loads ceil(INDEX.count/8) words before the row walk. Each word holds eight 32-bit indices, index r in bits 32*(r mod 8)+:32 of word floor(r/8). The final word can contain unused lanes. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:329-356, :905-918, :923-956; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:485-492; evidence: tests/sysnode/mm_mover_tb.v:528-564)
- **ISA.MV.051** `RTL` CTRL[17] clear selects u32 indices; set selects fp32. Accepted fp32 values are signed zero or positive integers below 2^31. Invalid fp32 records F_INDEX (10) when preparing its row. Earlier rows are not rolled back: a valid first row followed by an invalid second row writes the first and leaves the second unwritten. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:805-806, :415-424, :970-978, :1039-1048, :1071-1104; evidence: tests/sysnode/mm_mover_tb.v:494-526,528-550,567-584)
- **ISA.MV.052** `unproven` For GATHER or SCATTER, GO rejects an index count greater than mover.max_index with F_IDXLEN (1), before issuing the index-list read. Element-width code 3 takes precedence. The threshold is the RTL IDX_WORDS capacity multiplied by the number of 32-bit indices per word. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:898-916; evidence: implementation inspection only)
- **ISA.MV.053** `unproven` L1 gather/scatter lowering clamps initial index-count and row-word values to at least one. The typed emitter rejects index counts outside one through max_index, but row words need only fit unsigned sixteen bits and can be zero. L2 splits row words and index batches into moves; this is not a general L1 or typed-emitter splitting guarantee. Runtime register-patched values are not protected by the initial-value clamp. (code: software/kohakutpu/compiler/crates/ktpu-l1/src/lower/node/mover.rs:83-143, :383-419; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:477-504; software/kohakutpu/compiler/crates/ktpu-l2/src/lower/mover.rs:461-503; evidence: implementation inspection only; historical matching execution not established)
- **ISA.MV.054** `unproven` The encoder refuses an index-list base that is not aligned to `die.word_bytes` [32]. The mover itself sends the supplied index-list base unchanged as its first AXI read address; it does not clear the low address bits or check their alignment. (code: software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:477-490, src/kohakuaccel/sysnode/mover/mm_mover.v:842-844, :905-916; evidence: implementation inspection only; no misaligned index-list run established)

## 6. The transform slot

- **ISA.MV.060** `silicon` XFORM names its occupant on source HDR: transform id [50:47] and mode [58:55]. The mover forwards these to the transform slot. (code: software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:420-425, :469-475; src/kohakuaccel/sysnode/mover/mm_mover.v:820-821, :896-897; src/kohakuaccel/sysnode/core/mag_xform.v:125-172; evidence:  tally fn quant 172, gt4 442)
- **ISA.MV.061** `silicon` XFORM iterates source words and advances the destination once per entry. Each entry opens an OUT_WORDS output command of consecutive words at its destination address. Input-entry size follows the selected occupant geometry. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:275-295, :890-892, :684-688; src/kohakutpu/transform/xform_bank.v:69-77; evidence:  silicon `quant w(h1+0, (192, 32)) -> w(q+0, (24, 128)) bpack` (192 source words, 24 entries of 4 words))
- **ISA.MV.062** `unproven` L1 quant, gt4 and generic xform statements set W16. The low-level typed emitter does not enforce whole-entry source counts or require W16 for XFORM: it validates walker fields and accepts any supported element-width code. Whole-entry counts remain a caller obligation at this interface. (code: software/kohakutpu/compiler/crates/ktpu-l1/src/lower/node/mover.rs:289-333; software/kohakuaccel/compiler/crates/ka-isa/src/mover.rs:395-451, :469-534; evidence: implementation inspection only; complete historical execution coverage not established)
- **ISA.MV.063** `silicon` QUANT, id one, consumes eight words and emits four; mode bit zero selects B layout. GT4, id two, consumes and emits four words with output word i granule w equal to input word w granule i. Each 32-byte word has four 64-bit granules. (code: src/kohakutpu/transform/xform_bank.v:66-89, :99-138; evidence:  silicon `quant ... bpack`, `quant ...` (A packing), `gt4 w(x+0, (100, 2048), (16, 32), (4, 512)) -> ...`)

## 7. Completion and faults

- **ISA.MV.080** `unproven` I_DRAIN completes only when the write engine is idle, the command queue is empty, outstanding reads/writes, data occupancy and outstanding transform entries are zero, and transform serializer and output queue are empty. I_DONE increments the done count only if the fault code is zero, then returns idle. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:1088-1100; evidence: implementation inspection only; complete historical execution coverage not established)
- **ISA.MV.081** `RTL` A validation fault remains readable after return to idle. A later GO can replace it with the later validation fault: width code three reports F_EWIDTH (5), followed by a misaligned destination reporting F_ALIGN (6). (code: src/kohakuaccel/sysnode/mover/mm_mover.v:870-909, :1094-1104; evidence: tests/sysnode/mm_mover_tb.v:350-371)
- **ISA.MV.082** `RTL` Successful GATHER and SCATTER cases report fault zero. Done-count increment requires fault zero; returning idle alone does not indicate success. Other fault codes are ISA.MV.085 and ISA.MV.086. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:1094-1105; evidence: tests/sysnode/mm_mover_tb.v:458, :505, :546, :561 explicitly checks fault zero)
- **ISA.MV.083** `silicon` The sysnode reads MVSTAT as ROOM [33], busy [32], fault [31:28] and low 28 done-count bits [27:0]. Host AUX_STAT has the distinct layout in ISA.MV.087. (code: src/kohakuaccel/pe/rv64-sys/rv64_syscore.v:795; software/kohakuaccel/firmware/include/ka/hal/control.h:99-103; software/kohakuaccel/firmware/package/interp.c:499-510; historical equivalent: af7c1bb:software/firmware/kohakuaccel/package/interp.c:552-564; evidence:  silicon MOVER steps polled MVSTAT)
- **ISA.MV.084** `unproven` A move reaching I_DONE increments the done counter only if the stored fault is zero; I_FAULT does not increment it. Sticky configuration-queue overflow makes a subsequent GO initially select F_CFGQ, although later GO validation assignments can replace that code. An AXI error observed while the instruction state is not idle assigns F_AXI. In I_RUN, a processed element observing stored F_AXI selects I_FLUSH regardless of element kind, unless an earlier alignment or padding check selects that same transition with another fault code. Run accumulation for that element still occurs, and the error-detection cycle observes the previous stored fault because updates are clocked. Completion still depends on outstanding reads, writes and transform entries retiring; the RTL provides no timeout guaranteeing progress after an error. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:249-256, :701-702, :870-909, :1024-1058, :1083-1104; evidence: implementation inspection only)
- **ISA.MV.085** `RTL` Fault codes 5 element width, 6 alignment and 10 fp32 index. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:134-137; evidence: mm_mover_tb sections 6 (:352-371), 9 (:487-490), 10 (:514-526))
- **ISA.MV.086** `unproven` Fault codes are 1 F_IDXLEN (index length), 2 F_RANGE (range), 3 F_AXI (AXI response error), 4 F_MODE (mode or invalid transform geometry), 7 F_XPAD (transform source padding), 8 F_XFORM (transform-slot fault), and 9 F_CFGQ (configuration-queue overflow). F_RANGE is declared but never assigned to the fault output. (code: src/kohakuaccel/sysnode/mover/mm_mover.v:134-137, :434-441, :870-909, :965-978, :1024-1048; software/kohakuaccel/driver/kohakuaccel/driver/device/mover.py:73-87; evidence: implementation inspection including every stat_fault assignment)
- **ISA.MV.087** `unproven` The host AUX_STAT register at offset 0x0078 contains moves done [63:40] (the low 24 bits of the mover done counter), read count [39:24], write count [23:8], fault [7:4], zero [3:1], and busy [0]. - **ISA.MV.090** `unproven` A package MOVER step carries two ordered 64-bit register-offset/value pairs per 256-bit payload.
